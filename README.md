# 大富翁 11 · 网格复刻

纯前端、零后端、零依赖的《大富翁 11》规则复刻：把核心逻辑搬进浏览器，用方形图块和图标占位代替 3D 美术。

## 运行

```bash
python3 serve.py
# 打开 http://localhost:8000
```

`serve.py` 禁止缓存；改完 JS 刷新即可。也可以换任意静态服务器。

## 现在能玩什么（M1）

- 25×17 网格棋盘：路面 1×1 可走；地产 1×1 / 2×2 在路边；路面上的东西每格最多 1 个，三层互不冲突。
- 16 个地产簇，每簇 4 块，簇间留空；小地产全部贴路；每簇最多 1 块 2×2 大地产。
- 大地产先买空地，第二次投资 6 选 1；公园只能被改建卡改成。
- 随机初始位置/朝向，起点不触发；死路反弹，不强制传送。
- 回合：弃到 8 张 → 用卡/银行/股票 → 掷骰 → 移动 → 脚下东西 → 路面类型 → 相邻地产 → 方向。
- 经过生效只有银行、乐透、送卡格和地面道具；商店/神秘人/魔法屋/新闻要停下。
- 现金/存款分离；租金进存款；购买只用现金；银行存取与利息。
- 商店 9 张买 3、神秘人 6 张买 2，买过消失；乐透 1–30 号码、去重、开奖累计；股票随时买卖。
- 48 张卡与五合一；10 位神仙；7 种大建筑；4 位领主 × 3 档。
- 右侧 390px 侧栏：状态一行式、日志占中间、底部情境区；卡片扇形叠放；人物带方向指针。
- 2–6 人热座；领主可由人操控；固定种子可复现。

## 目录

- `docs/`：问题、目标、需求、用例、产品、路线、实现现状；`docs/data/` 是原版资料与缺口。
- `src/engine/`：规则内核（纯 JS，可在 Node 无头跑）。
- `src/data/`：角色、卡、地图、调参表；未证实系数集中在 `tuning.js`。
- `src/ui/`：网格棋盘与侧栏。
