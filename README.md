## 从干净检出玩一局（本次已复验）

```bash
python3 -B serve.py 0      # 打印 LISTENING <port>；端口交给系统分配，不占 8000
```

打开 `http://127.0.0.1:<port>/index.html?slice=1&style=grow&seed=1`。页面停在第一屏，
先在三张起手（街角店主 / 机会买家 / 穿街高手）里选一张，再点「开一局街角生意」。
三张卡上写着各自的开工现金（42,000 / 45,000 / 46,000）——差别写在屏上，不是隐藏属性。
三张卡的起手牌不同（街角店主 翻修+旺季+定步 / 机会买家 收购+定步+停业 /
穿街高手 停业+定步+翻修），“三种打法”靠卡表 —— 牌面在局内手牌区可读。
胜率**不一样**：同一套 AI、走真实入口、每格 300 局，目前是
45.7% / 32.0% / 34.7%，最弱与最强相差 13.7 个百分点。
改前（未调开工现金）是 52.3% / 9.7% / 10.3%，相差 42.7 个百分点 ——
**这个 42.7 是改前的差距，不是任何一条起手的胜率**；不要与 #3330 报过的那组胜率混淆。
能说「分得开」的只有一对：街角店主对机会买家（95% 区间不相交）。
另两对（机会买家↔穿街高手、街角店主↔穿街高手）的区间仍然重叠，这个样本量分不开它们。
所以这一刀把「一个选择加两个陷阱」改成了「三条都能赢，但还没一样强」——
数字与复跑命令见 [RESULT-3331](docs/evidence/RESULT-3331.md)，量具是 `node tools/balance-slice.mjs`。

**第一回合真正要作决定的地方**：起手只是选打法，第一个有后果的选择在局内。
「机会买家」的收购卡是第一处被修好的：它以前把**空地**也当目标，而对任何目标都收 125%
（那 25% 是付给原主人的溢价，空地没有原主人）——于是每个目标都凭空亏 2,000，
AI 在 40/40 局里一次都不用这张卡。现在它只收**别人已开张的店**，选目标那一屏
t逐个列出「买下后每局大约能收多少」，因为四个候选的价与标称租金完全一样，
真实差别在**哪条街有人走**（n=300 同种子实测：灯火街 19.3%，晚风街 5.0%）。
改完平衡表**逐位不变**（45.7 / 32.0 / 34.7）—— 修的是合法目标与呈现，不是力度。
细节与反例见 [RESULT-3332](docs/evidence/RESULT-3332.md)。

**更早的一处：第 1 天第 2 个决策就是「加盖 10,000」。** 街角店主与穿街高手的起手带「翻修」卡，
所以这一屏其实是一个三选一，而改前只印了三个数里最好看的那个（「估值增加 4,000」，
而当场总资产是 **−6,000**）。现在它把当场三笔账并排给出，并说明那张免费卡能做什么：
不付的话，那张卡下回合免费把它升到 2 级；要到 3 级，先付再免费共 10,000、先免费再付要 15,000。
同种子反事实（seed 1–40 × grow/cross，只改这一下）：付的那臂平均资产 **−9,896**，
但 71 局里有 19 局付了更好 —— 所以这是个要看理由的选择，屏上原先没给的就是理由。
细节、两个负对照与 390×844 的几何读数见 [RESULT-3334](docs/evidence/RESULT-3334.md)。

**那一句在第 16 天是假的，已改。** 上一版把「翻修卡**下回合**免费升到 2 级」原样印到最后一屏，
而第 16 天按「放弃」就直接结算 —— 没有下回合，那张卡再也用不上。
现在最后一天只说这局真做得到的事（`这是本局最后一天，没有下回合：不付就停在 1 级，翻修卡再也用不上。`），
三笔当场账原样保留，非最后一天的句子一个字未动。
同一天还修了给读者的手机复验入口：`support/probe-3334/geom.mjs` 改前从本机 `.scratch/` 起静态服务，
干净副本上会 ENOENT；现在只用随仓库走的文件。见 [RESULT-3335](docs/evidence/RESULT-3335.md)。

**「这局跑的是哪一版、浏览器收到的就是那一版」现在是一个可重算的断言。**
这一轮没有动任何产品字节（35 个文件与上一版逐字节相同，锁仍是 `slice-entry-3335.sha256`），
动的是**证明本身**：三个工具原来各自写死了一份「当前锁」，其中 `verify-http.py` 停在上一版，
而且只核 5 个样本文件，恰好漏掉那一版唯一改过的 `src/ui/slice.js` —— 所以 `receipt-3335-final`
里那句 `SEALED` 是不成立的（它的 E 项仍然成立，见下）。
现在当前锁只活在 `docs/evidence/current-lock.txt` 一行里，封印改成核**整把锁**，
并把每个响应的完整摘要写进回执（`verify-receipt.py` 的 F 项），拿到回执的人可以自己重算。
索引里「当前」也不再由人写，而由测试对着指针核。见 [RESULT-3336](docs/evidence/RESULT-3336.md)。

**打完一局，屏上那句「下局试试」现在说的是这一局。** 它原来是三条按起手写死的推销句，
与本局无关；其中「带现金收购别人养好的店」实测是**最差**的一条路（同 seed 配对 300 局：
胜 126→60，终局资产均值 −20,945）。现在换成 `nextGameLine(state)`，数全部从本局
state/log 算，并且只说本局真发生过的那一种：破产了是哪一笔击穿的、街心书屋被谁哪天用多少钱拿走、
它是空地时买下后每次能收多少、已经归我时再往上盖要多少钱。
街心书屋是本片测到的最大正杠杆（同 seed 配对：原本没人买而这一臂买了的 40 局里，胜 12→32，
资产 +19,805），而旧文案一个字没提过。
顺手修了一处一直存在的遮挡：那句话在 390×844 上被 sticky 的「再开一局」盖住（句 754–792、
按钮 734–782），读不到就等于没有。见 [RESULT-3337](docs/evidence/RESULT-3337.md)；
复算：`node support/probe-3337/big.mjs 300`、`node support/probe-3337/line.mjs`。

**买地和打完后的那句建议，现在说的是同一份账。** 上一版两屏打脸：买地时劝退
（「72 局里有 56 局的整局租金还不够这一笔」），打完却叫你「第 4 天开售就去拿街心书屋」。
根因不是文案，是口径：买地是**资产换手**，不是花掉 —— 真 `buyPlot` 前后总资产差 0
（现金 −26,000、地产标价 +26,000，三种起手都一样）。租金要盖的不是那 26,000，
而是这笔现金被占住的机会成本。现在两屏共读 `src/engine/market-ledger.js`：
买地屏给三行（本局总资产不变 / 买完剩多少、够付对手最贵的一次租几次 / 72 局里对手踩到它几次），
结算屏按同一份表说话，并且不再叫你自己走到自己店旁边 —— **自己的店不收自己的租**
（实测：我持有书屋的 31 局里，31 局都发生过「我自己停在它旁边」，合计 155 次，一分钱没有）。
顺手修了三个真缺陷：书屋加盖报 15,000（引擎实际扣 30,000，那是小店价）；
买不起时屏上算「现金 13,000 → -13,000」「够付 -3 次」；终局停业时旺季那句写成「0 变 0」。
见 [RESULT-3338](docs/evidence/RESULT-3338.md)；复算：
`node support/probe-3338/ledger-table.mjs 24`、`node support/probe-3338/geom.mjs`、
`node support/probe-3338/settlement.mjs`。

### 第二入口（8001 对照页）

对照页 `/.scratch/af-variant.html` 需要一个额外的静态服务，**唯一权威入口是 `support/serve-variant.py`**：

```bash
python3 -B support/serve-variant.py 8001
# 打开 http://127.0.0.1:8001/af-variant.html
```

`support/serve-variant.py` 与 `serve.py` 同一套内部目录拦截（但不拦 `.scratch` —— 对照页只能从那里取），
并且同样支持 `python3 -B support/serve-variant.py 0` 由系统分配端口（stdout 会打印 `LISTENING <port>`）。

> 历史：这个入口原先住 `.scratch/serve-variant.py`。`.scratch` 是例行清理的 ignored 目录，
> 2026-11-22 被清掉后，仍在跑的 8001 进程 argv 指向了一个已不存在的文件 ——
> 重启会直接失败。现在副本在 `support/`（随仓库走），`tools/verify-full-game.mjs` 与
> `tools/verify-grow-panel.mjs` 也都用 `support/` 的路径起服务。

## 现在能玩什么

- **大酒店地图**：27×19。中央是一块 3×3 的大酒店，四周 12 个路面格全部与它相邻；四角各有 2×2 大地产，被三条路包住，形成 6 个入口。
- 开局有 13 块无主已建地产：中央 Lv.3 大饭店、两块四角 Lv.2 大建筑、外圈和內圈的小房屋。买下前不收费，买下后继承等级和类型。
- 移动是逐格真实行走；进入岔路先选方向，停在岔路再定下回合朝向。死路反弹，传送门保留剩余步数。
- 回合：弃牌 → 用卡/银行/股票 → 掷骰 → 逐格移动 → 脚下东西 → 路面类型 → 相邻地产 → 方向。
- 买地、加盖、大建筑、街区倍率、租金、现金/存款、银行利息、股票、乐透、商店、研究所、魔法屋、新闻、神秘人、野狗、乞丐、医院、监狱、52 张卡、10 位神仙、7 种大建筑、4 名角色 × 3 档。
- 7 种大建筑各有不同收益：商业中心转盘租金，大饭店双倍租金并强制住店，书店产卡，能源中心提高对手买卡价格并收能源费，地产公司降低己方租金，研究所产进阶卡，公园不收费。
- 12 张地图：大酒店、雪国、云上庭院、机械迷宫、不夜天、水乡、山城、天使岛、狂欢节、音乐之都、锦绘时代、火山古迹；各有独立机制。
- 6 个五卡合成、10 位神仙、4 名角色 × 3 档、16 名角色天赋。
- 2–20 名参赛者，人类/AI 混排、任意队伍、热座；固定种子可复现。
- 右侧可拖宽侧栏；地图直接点选方向、卡片目标和障碍位置；金额/卡牌/状态飘字 2.4 秒。
- 角色说话时，地图 token 上方弹出漫画气泡，气泡和语音同句；游戏等气泡结束再继续。点击气泡或空格可跳过；没有中文语音时只显示文字。
- AI 动作之间有停顿；AI 会评估中心大酒店、邻接地产和对手建筑。
