# 大富翁 11 · 文字复刻

一个纯前端、零后端、零依赖的《大富翁 11》规则复刻：把原版的核心逻辑与信息搬进浏览器，用文字、色块和 SVG 代替 3D 美术；没有音乐/语音也能玩，有素材时再叠加。

## 运行

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

不需要安装、不需要构建、不需要联网。也可以直接用任意静态服务器托管这个目录。

## 现在能玩什么（M1）

- 2–6 人热座，人机混合与队伍划分在引擎层已支持；M1 默认全人类。
- 自由乱战，或 1 位领主 + 挑战者；领主先手，有 3 档难度。
- 一张“测试庄园”图：48 格主环 + 监狱/医院侧路 + 死路传送门 + 活动机关板。
- 回合：弃到 8 张 → 用卡/操作 → 掷骰 → 移动结算 → 换人；掷骰后不能继续操作。
- 岔路：有剩余步数随机非来路，正好停在交叉点由玩家选方向。
- 地产：买地、加盖、同街道指数租金、队伍免租、破产、时间到按资产。
- 48 张卡（含 6 张五合一进阶）、商店、研究所、手牌上限。
- 10 位神仙、7 种大建筑、银行/股票/乐透/魔法屋/新闻/神秘人/野狗/乞丐/医院/监狱/载具/物价。
- 4 位领主 × 3 档技能（反噬、章鱼免疫、熊的强化/复活、圆圆的利息/抽成）。
- 固定种子可复现。

## 测试与模拟

```bash
node --test
node src/sim.js --games 100 --seed 1
node src/sim.js --games 50 --seed 3 --boss doctor --tier 3
```

## 目录

- `docs/`：问题、目标、需求、用例、产品、路线，以及 `docs/data/` 的原版资料与缺口。
- `src/engine/`：规则内核（纯 JS，可在 Node 无头跑）。
- `src/data/`：角色、卡、地图、调参表；未证实系数集中在 `tuning.js`。
- `src/ui/`：文字棋盘与面板。

## 已知近似

原版不公开精确公式。租金、物价、利息、股票、彩票、事件金额与部分概率是“逻辑相符、量级合理”的可调近似，不是原版数值；`docs/data/` 里逐条标了已证实/未证实。地图方面，M1 用自设计的全系统测试图；16 张原版/同构图在 M2。
