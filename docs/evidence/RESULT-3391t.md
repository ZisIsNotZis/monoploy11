## 一、我自己的结论被自己的对照实验推翻（必须先讲）

上一版（RESULT 的 3d 节）说「营业进项做成了本片第一条真正的两种打算」：
照常打 +17.8pp，且「只开街 − 只抢书屋」的符号随起手翻（grow +30.0 / take −16.7 / cross −11.7）。

这一轮加了两支对照，把它拆开了：

1. **等额白给现金对照**（`support/probe-3391/income-control.mjs`，n=180/格）——
   把进项换成「每人每天白拿 800」（≈ 同一笔钱、无任何所有权条件）：
   - street 进项 − plain = **+17.8pp [11.1, 24.4]**
   - flat 白给 − plain = **+0.6pp [−7.8, 8.9]**
   ⇒ 收益不是「场上钱变多」（#3391f 的财富效应在这里不解释它）。

   **这句「规则确实在奖励一个行为」是错的，已撤回（#3391u / 复核 #3424 / supervisor 独立复现）。**
   错因在对照臂本身：`flat` 是「**三家**每天各白拿 800」—— 它同时抬高了对手，
   于是一个只给一方的效应会被自己抵消掉，印出来就是 0。对照臂的**受益集合**
   必须与处理臂相同，否则那个对照不叫对照。

   补上正确的那一格（`seat-or-behaviour.mjs`，n=2700，三把椅子都轮换）：
   `flat0` = **只给受试座位**每天 800、无任何所有权条件 ⇒ 座位 0 上
   `street − flat0 = −4.9pp [−7.1, −2.6]`，即「开进项」还不如「白给同样多的钱」。
   三把椅子轮换后 `street − plain = 0.0pp [−1.6, 1.5]`，而分座位是
   **+17.3 / −9.3 / −8.2pp**（椅子 0/1/2）—— 这条规则不提高总量，只把胜率挪给 0 号椅。
   ⇒ 它是**座位红利**，不是「第二条路子」，也不是「奖励行为」。

2. **按座位拆 + 比两张发牌表**（`support/probe-3391/income-by-seat.mjs`，n=180/格）——
   - 争街（产品默认）：0 号位（= 人类坐的那张椅子）局均 **12,943**，两位 AI 平均 **2,894**，**4.5 倍**；
     0 号位终局凑齐 0.92 条街，AI 0.19 条。
   - 整条街表（`?cross=0`，三家开局都独享一条街）：0 号位 15,054 vs AI 17,237 = **0.87 倍**（对称）；
     进项整体影响 **−3.9pp [−11.7, 4.4]**；「符号随起手翻」**消失**
     （小店路 − 书屋路：grow −6.7 / take −28.3 / cross −26.7）。

   ⇒ 根因是发牌几何，不是起手牌：0 号位两条街的另一半是**无主空地**（走过去按 8,000 买），
   两个 AI 的另一半**互为对方**，只能靠收购卡，而收购实测负期望、AI 从不选（#3346）。
   ⇒ **3d 的「两种打算」撤回**。这条规则目前是「给一个座位发钱」，不是第二条路子。
   默认关闭这件事是对的，理由从此换成上面这一条。对照页第一屏已按这个说法改写。

## 二、supervisor 报的回归：开局选择没被记住

根因是我上一版留下的：`startSlice()` 里

```js
const u = new URL(location.href);
u.searchParams.set('cross', contested ? '1' : '0');
```

—— 造了 URL，**却从没写回地址栏**，而紧邻的注释写着「用 replaceState 而不是改 href」。
注释声称的行为 ≠ 代码，这就是他手选「整条街」、再打开却回到默认争街的原因。

修法：真的 `history.replaceState(null, '', u.href)`，并把**布局与规则**一次写全。
同一处还修了两个「屏上 ≠ 实际」的隐患：规则改成从**屏上的选择**读（不再读进场时的 qs 快照）；
地址栏带来一个不在两档里的 `?business=300` 时，把原值列进单选而不是静默回落。
