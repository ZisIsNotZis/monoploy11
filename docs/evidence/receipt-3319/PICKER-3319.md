# #3319 选街屏：屏幕劝你选错的那一条；以及两处「画得出、点不着」

这一片只改一件事的**判断依据**：旺季 / 停业的选街面板现在按「对你值多少」排序并直接点名。
它顺带暴露出两个同源的窄屏缺陷（手牌点不到、作答后点击被吞），一并修了。

## 1. 选街屏：排序键与卡面互相打脸

**为什么会挑这一处。** 首局里最像「两个都说得通」的时刻，是第 4 天手上有旺季、自己两条街还没进旺季的那一屏：
开在自己街上 vs 开在对手街上，方向相反、都讲得通。可我把它点开后发现，**面板的顺序和卡面说的不是同一件事**。

| 缺陷 | 事实 |
|---|---|
| 排序键错 | 面板按 `|对手每次租金变化|` 降序，卡面/补给屏按「对你的净收益」。于是「帮对手最多的街」排第一。实测 142 帧人类选街屏：**45 帧**里对你最优的街不在 4 条可见行内；**63 帧**旺季屏第一行就是亏钱的选择 |
| 「用卡后」是假数 | 引擎（`src/engine/game.js:543/500`）只把计时器**重设**成 3/2 天，不叠加；`rentFor` 只要 `inflate>0` 就已翻倍。旧公式再乘一次，把已翻倍的 22,400 印成 44,800。实测 2,668 条可见行里 **58 行**是这种假数字，且因变化量最大被错排序顶到最上面 |
| 不变的数字占整行 | `你22,400→22,400` 在 390×844 把这行从 22.4px 撑到 44.8px，面板下沿越过 `#hand`，**「取消」点不到** |

**改法**（`src/engine/insight.js` + `src/ui/render.js`）：
- `streetCardModel` 的「用卡后」不再用「×2 / 归零」推，改成**照引擎改一次计时器 → 读同一个 `rentFor` → 立刻恢复**
  （与 `upgradeAfterLine`、`buildOpportunityLine` 同一套只读夹具）。净收益 `net` 现在挂在**每一行**上，
  卡面（`supplyWorth`）、排序、标题点名三者共用这一个数 —— 上一版在 `insight.js` 与 `render.js` 各写一份，
  两份必定漂移，而漂出来的正是「两屏互相打脸」。
- 标题的四种局面各说各的话（都在真页面量过是 1 行、取消命中 `itself`）：

  | 局面 | 屏幕上的字 |
  |---|---|
  | 有正收益 | `对你最值 +11,200 · 晨光街` |
  | 最好也是负的 | `最好也亏 5,600（晨光街）` |
  | 最好是 0、其余是负的 | `晨光街 不动账，其余帮对手` |
  | 全是 0 | `全都不动账` |

  第二/三种必须分开：旧版本会对 grow/1 D4 说「这些街对你都不动账」，而那一刻另两条街各帮对手 5,600。
  **这是本轮我自己写出来、又被自己抓到的假话。**

## 2. 窄屏两处「画得出、点不着」（同一根因：可点 ≠ 会被接住）

- **手牌整排点不到**（`styles.css`）：390×844 动作屏 `#hand` 被压成 60px 而内容 259px
  （同一时刻 `#insight` 151px）。`flex:0 1 auto` + `overflow:visible` ⇒ 被压小且不滚，
  `#cards` 从 823 画到 1036、越过 `#hand` 的 837 边界，落在窗口外（页面不可滚）。实测 **usable 0/3**。
  这不是本片引入的：线上 `7ad1f8a` 同视口同走法实测同样 0/3。
  修法沿用本文件已有的、已验收的形态：手牌在窄屏排成单行横向滚动、`#hand` 按内容高占位、
  剩余空间给 `#insight` 并让它自己滚。**代价写在明处**：这一档动作屏上 `#insight` 不再是 151px 常驻大块。
  实测 390×844 / 360×640 / 1280×800 三个视口都是 **usable 3/3**。
- **作答后点击被静默吞掉**（`src/main.js` 的 `answer()`）：D4 补给屏实测被连点 **13 次**，
  每次 `hit=itself`、`logLen` 恒 1314，直到气泡播完才关 —— 后面 12 次点击全被 `if (!active) return` 丢掉了。
  原因不是节奏，是「画得出可点」不等于「点了会被接住」。修法：非动作屏作答后立刻把这一屏的按钮全部置灰。
  **效果**：同一走法 76 次按压 → **64 次**，`stillEnabled=True` 的按压 0 次，连点告警消失。

## 3. 判据也改了两处（都有反例）

- **F7（新增）**：选街屏的「取消」必须**按到了并且屏真的关了** ——
  判据只认 `hit == 'itself'` 且按下后 `panelHidden` 且手牌回来，不拿几何数字冒充「点到了」。
- **F6（收紧）**：原来只对动作屏发言（非动作屏作答后不重画，量具问不出所以然）。
  现在扩到**所有屏**：按下的控件 80ms 后仍 enabled，在任何一屏都是「点击没被接住」。
  收紧后上一版回执 `receipt-3317-390` **如实变红**（它的 pressLog 里就带着 28 次这种点击），
  所以交付的证据换成本轮这一份。
