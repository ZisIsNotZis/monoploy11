# #3339 买地屏的单位：租金按「次」收，不是按「回合」收

起点 `d745fe2`（#3338），分支 `release/3331-starter-evidence`。**未推送、未删任何目录。**

**结论：这个候选在当前产品上不可达，所以我没改它。** 顺带记一条量具的教训：
第一版（`trap.mjs`）只看了 `valid`、没看外层，于是把「卡已用完时所有卡本来就 disabled」
数成了 113 次「点了没反应」。错在量具，不在产品 —— 差一点就去修一个不存在的东西。

## 真正的缺陷：同一屏上两本账

被否掉的候选把我带到了同一屏的另一句。买地屏在我上一片新加的三行账**正上方**写着：

```
此刻这条街 租 4,000；账面约 7 回合回本（对手不走过来就不兑现）。
…（我新加的三行）
同规则 72 局…：先拿到它的 31 局里…平均实收 11,948（5 局一分没收到）。
```

7 回合 vs 整局实收 11,948（标价 26,000 的 46%）—— 两句都是真数，读起来却在互相打脸。

**根因是单位，不是数字。** 引擎里租金只在有人**停到这块地上**时才收
（`flow.js:659` 的「实付租金」行写在 `groundPhase` 里）。产品里从来没有「每回合收一次租」
这件事。旧句算的是 `ceil(售价 / 每次满租)` —— 那是一个**次数**，却被叫作「回合」。
把次数当时长，玩家就会以为等 7 回合钱自己回来；而真正的变量是「对手会停过来几次」，
正是我上一片那张 72 局表在讲的事。

这就是 `#3358` 让我修的那个病换了个位置：不是两块屏各说一套，而是**一屏之内两句各说一套**。
上一片我只把新加的三行对齐了，没回头读它上面那一句。

## 改了什么

`src/ui/render.js` 一处：

```
此刻这条街 租 4,000；账面：按这个价收到 7 次才够本
（租金只在对手停到这块地上时收，不是每回合收；对手不走过来就不兑现）。
```

- 数是同一个 `roundsToRecover(price, rent)`（仓库唯一的 ceil 实现），没改算法，只改**单位**与
  前提。它现在与下面那张表说的是同一件事：一个说「要收几次才够本（7 次）」，
  一个说「实际一局能收到多少（平均 11,948）」—— 玩家自己能看出差在哪。
- 停业那一支（`rent === 0`）不动：它本来就不报次数。

## 判据这次改在哪，为什么必须改

`test/midgame-buy.test.js`：旧断言 `账面约 (\d+) 回合回本` 只在验
`ceil(售价 / 租)` 这个算术 —— 它**和产品一起用错了单位，所以一直是绿的**。
这是同一种病的第三次：判据复述产品的公式，于是产品错它也错（前两次是
`buildCost(3)=15,000` 与「自己走到书店旁边收租」）。

现在钉三件事：
1. 次数 = `ceil(售价 / 买下后的租)`（独立算，不读产品里的数）；
2. **禁止再出现「回合回本」**（`assert.equal(/回合回本/.test(choice), false)`）；
3. 必须写出前提「只在对手停到这块地上时收」。

停业那一支的断言也从「不许报回合数」扩到「不许报次数」。

## 监管者的真机确认

监管者在 390×844 上看了这一版买地屏，原话：四千一次、满租要收七次，
与下面的整局实收能同时读懂，买和放弃也还按得到。他要求把这条修正连同账本一起
自验并固定下来，以这个版本作发布验收 —— 所以这一片把锁、回执、交付集、索引全部
重签到了 `slice-entry-3339.sha256`，没有只改一句话就走。

## 没做到 / 不能证实

- **仍然没有任何玩家会因此改主意的证据。** 这一片证明的是：句子的单位与引擎的收费时机
  一致（按次，不按回合）、数与下面的 72 局表不打架、两种文案长度在 390×844 上都不被遮。
  这三件都不是「玩家读完会换一个打法」。
- 「7 次」仍是**账面**：它假设每次都收满租。等级与旺季都会把这个数改掉，
  而对手停几次不由玩家决定 —— 句子里写了这一点，但没有把它折成一个「按实测频率要收多久」
  的数。要那样写，得先有「我持有它期间每局被停几次」的分桶（这次量到的是
  对手 1.74 次/局、自己 4.03 次/局，但那是按整局算、没按天数归一到「回合」），我没有。
- 没动引擎结算、没动平衡，所以平衡表没有重跑。
- `flow.js:209` 那条静默跳过仍然存在（代码里确实有 `continue`），只是当前产品上
  不可达；若将来 `sliceTargetIds` 的规则收紧到「中间回合可能有卡没目标」，它会重新变成
  玩家的真问题。这条留作候选，不在这片修。
