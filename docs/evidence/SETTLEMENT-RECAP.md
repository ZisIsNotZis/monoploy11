# 收摊时看见这局真正做成的选择

「街角生意」结算在排名下展示最多两步已经兑现的选择，再开一局仍贴在首屏。没踩到免租点的停业不算省钱。收租用实际进账，满额牌价只作为规则参考。局中规则和营业开关沿用原版。

## 两种手机尺寸的实局

用默认争街、机会买家、种子 47 开局，保持营业关闭。第 2 天停了晚风街，实际走到晚风街茶铺旁免租。第 4 天定步 6 步，花 26,000 买书屋，之后实收 9,600。两种手机尺寸的排名资产均为 91,600 / 79,000 / 78,400。

## 复跑

在仓库根目录，用本地静态服务打开游戏：

```sh
python3 -m http.server --bind 127.0.0.1 8000
```

另一个终端用 Node 22+ 和本机 Chromium 运行：

```sh
node support/settlement-recap.mjs 8000 /tmp/slice-recap-360
node support/settlement-recap.mjs 8000 /tmp/slice-recap-390 390 844
node --test test/slice-recap-moments.test.js test/next-game-line.test.js test/slice-zero-rent.test.js
```

浏览器从普通入口启动并完成整局，开局和再玩使用触屏事件，中间沿实际界面动作回放。21 项相关测试通过，覆盖未兑现的动作、实际到账、回顾排序和可选营业。两局复验说明结算能回顾已有选择，重玩意愿仍待体验。
