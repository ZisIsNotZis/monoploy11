# #3340 选落点那一屏：自己的店被印成一个租金

起点 `ee8c357`（#3339），分支 `release/3331-starter-evidence`。**未推送、未删任何目录。**

## 先说我本来要做的事，和证据怎么把我改掉了

任务要的是「看懂账之后有没有几个真的想试的打法，终局会不会让我想换一个打法再开一局」。
我先按这个方向量「有没有第二个打法」——**答案是没有，而且不是文案问题**：

| 配对臂（同 seed，只改人类座位，其余交给同一套 AI） | 终局资产差 | 判定 |
|---|---|---|
| 补齐半条街（定步指到自家街的另一半） | **0** | 地图上不存在这种缺口：三起手开局各自**整条**拥有一条街 |
| 见到补齐机会就买 | 0 ~ +20 | 120 局里只触发 1–2 次 |
| 见加盖就加 | −505 ~ −3,155 | 记分上净亏：付 10,000，标价只 +4,000 |
| 旺季压在自己最贵的街 | −930 ~ −2,825 | |
| 停业压对手最贵的街 | −1,570 ~ −6,380 | |
| 定步去跑现金格 | −175 ~ −2,540 | |
| 能买书屋就买 | +660 ~ +955 | 但 120 局里只比默认多买到 **3** 局 —— AI 本来就买 |

结构原因（120 局，grow/take/cross × seed 1–40）：

- 45.2 回合/局，**52.6% 的落点挨着某块地**；挨着的地里 **我 2,055 / 对手 510 / 无主 289**。
  也就是约 **73% 的「停在地旁边」发生在自己的地上**，而自己的地不收租（见下）。
- 因此每局只有 **4.31 次**真付租。收入结构：工资 5,000 / 金钱格 6,383 / **收租 7,660** / 付租 7,395。
  租金几乎是零和。
- 地 5 天就买光；13 块地开局全是「预建但无主」。

**结论：本片不假装造出第二个打法。** 那不是改一句文案能做到的，而把记分改掉（让加盖按造价计）
在两种记分下量过，人类胜率 31.7% → 34.4%、冠军换人 18.3%，但配对臂仍是 0 或负 —— 换记分不会凭空长出打法。
所以我把这一片收在**唯一一处「玩家看懂了账却仍然会被骗」的地方**，它是上面那个结构问题的直接产物：

## 缺陷：最能拉动你选那个点数的数，在你自己的店上不会兑现

定步屏是全游戏**唯一**由玩家直接选落点的地方。

- 改前（`landingText`）：`晨光街茶铺：己方 · 租 2,800`
- 引擎真做的事（`flow.js` 付租分支第一句）：`if (owner?.team === p.team) { …问要不要加盖…; continue; }`
  —— 自己的店**不收自己的租**；#3338 已实测 31/31 局、155 次停留、一分钱没有。

量级（120 局，`node support/probe-3340/mislead.mjs 40`；本片第一版把路径写成 `.scratch/3340/…`，
那是不入库的本机草稿目录，干净检出上跑不了 —— #3341 把量具搬进 `support/probe-3340/` 并改了这里）：

| 点选项 | 20.8 个/局 |

## 改了什么

`src/engine/insight.js` 一个文件，收出一个措辞入口 `plotVisitLine`（`landingText` 与岔路前瞻
`routePreview.outlook` 都走它，两处不再各写一份）：

| 归属 | 改前 | 改后 |
|---|---|---|
| 自己的店、未到顶 | `己方 · 租 2,800` | `你的店 Lv.1 · 停在这里可加盖 10,000` |
| 自己的店、已到顶 | `己方 · 租 8,000` | `你的店 Lv.3 · 自己停在这里不收租` |
| 自己的店、停业 | `己方 · 停业 · 不付租` | 不变（这一句本来就是对的） |
| 对手的店 | `机会买家 · 租 2,800` | `机会买家 · 付租 2,800` |
| 无主地 | `可买 8,000` / `第 N 天开售` | 不变 |

为此 `landingInfo` 多给两个字段：`rentToMe`（我停在这里的钱往哪走；自己的店恒为 0 ——
这是**引擎事实**，不是措辞）与 `canBuild` / `buildAskCost`（自己店旁引擎真会问的那件事，
价与 `flow.js` 的加盖询问同源 `buildCost` + `price_big` 30,000）。

**没改**：引擎结算、平衡、地图、AI。

## 负对照（这条判据真的会红）

把 `plotVisitLine` 的己方那一支改回 `return '己方 · 租 ' + p.rent.toLocaleString()`：

```
✖ plotVisitLine 是唯一措辞入口：三种归属都说得清
  actual:   '己方 · 租 2,800'
  expected: /可加盖 10,000/
```

恢复后 7/7 绿。**判据钉的是「句子说的东西 = 引擎真做的事」**（引擎在自己店旁不收租），
不是「句子等于我的算式」—— 这正是 #3339 记下的那条教训。

## 我在这一片里被自己的量具骗了四次（都记下来，因为它们都会重复咬人）

1. **`initialProperties` 不是「开局已拥有」**，而是「13 块预建但无主」。我拿它当拥有清单，
   于是「多买地」臂恒报 0，我差点读成「产品不允许买地」。判归属只能读 `properties[id].ownerId`。
2. **按 `label` 认路面格**：43 个格子里多个共用「街道」，全塌缩成一个 → 「52.6% 落点挨着地」先被算成 0%。
   要用 `ui.step(state, p, next)` 给的 node id。
3. **日志里没有「发薪处/零工」字样**：工资行是 `经过起点 +N`（`flow.js:299`），
   金钱格是 `在金钱格获得 N`（`flow.js:437`）。按想象的字符串解析，工资/零工都读成 0。
4. **定步在切片里问的是 `type: 'diceValue'`（min 1 / max 6）**，不是 `'steps'`
   （`'steps'` 只属于完整模式的超级骰子）。我按 `'steps'` 接，于是「人人都会遇到的这个决定」量出来是 0 次/局。

还有一次是**我自己写错的反事实**：最初把「翻修卡免费升的层」也按 10,000/15,000 记成资产，
凭空造出 +39,328 的资产差。改成只记**真花出去**的造价后，效应缩到 +1~2 个百分点。
这一条如果没自查，就会变成「改个记分公式能让游戏好玩 40%」的假结论。

## 仍然没证实的（不要当已证）

- **没有任何「玩家读完会改打法」的证据**，也没有「想再来一局」的证据。证明的只是：
  这一屏上不再有一个不会兑现的数、自己的店说的是引擎真做的事、两处（落点说明与岔路前瞻）同源、
  改后 5,977 个点选项里 0 个再出现旧的假数。
- **第二个打法仍然不存在**（上表）。要造出它得动结构 —— 给地更多入口、让地 5 天后还能买到、
  或者让「停在自己的地上」真的产生点什么。这些都是设计改动，需要单独一片来验，本片没做。
- 没动引擎结算与平衡，故平衡表（45.7 / 32.0 / 34.7）未重跑。
- 回执只覆盖 390×844 + CDP 鼠标；不是真机触屏，360×640 未在本片实测。
