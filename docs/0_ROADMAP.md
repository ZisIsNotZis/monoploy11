# 路线

目标：纯前端、网格棋盘的《大富翁 11》规则复刻；三层（路面/地产/放置物）、热座、可结盟、规则型 AI、无后端。
预算：¥100 上限；预期现金支出 ¥0。

每个里程碑都是一个用户能打开、能玩、能判断的竖切片。资料整理不是里程碑，是 M1 的前置工作包。

## 2026-10-29 路线修订（网格与三层）

- 原判断：棋盘先画“节点+边”的拓扑，再把路面/地产塞进去；大地产做成两个连续路格。
- 事实/用户纠正：棋盘就是一张网格；路面 1×1 可走，地产 1×1/2×2 在路边且不可走；路面上的东西是第三层。大地产是一整块 2×2，不是两格路。
- 代价：M1 的地图与渲染重写；旧环图只保留为测试数据。
- 放弃：环状拓扑优先、把地产当路格、死路强制传送（改为反弹）。

## M2 全内容与对手

16 名角色天赋；48 张卡全部接入；10 位神仙；7 种大建筑；4 位领主 × 3 档；16 张图（网格重画）与热斗/抢房；规则型 AI；结盟提议/接受/背叛；魔法屋/新闻/事件全部选项。

验收：每个角色天赋在对应触发下生效；每张卡有获取方式并能结算；每档领主只启用该档技能；所有地图校验器全绿；AI 能独立打完一局；结盟改变租金与胜负判定；路面事件 + 地产同点结算完整。

## M3 体验层

2D 标识/头像、角色台词、浏览器 TTS、BGM/音效、金币飞字、骰子/移动/爆炸轻动效、地图配色、资产榜/新闻横幅、选人/开局界面、快捷键、跳过动画。动画只做 CSS/短过渡。

验收：关掉素材仍能完整游玩；打开素材有角色辨识度与反馈；无外部网络请求；移动端可操作。

## M4 平衡与发布

数值调平；README；静态部署；1000 局模拟；发布报告。

验收：公开链接可玩；README 含 30 秒上手与已完成/未完成；1000 局模拟无死锁。

## 记录

- 资料边界：16 角色、16 图、4 领主、48 卡；国服改名版不单独复刻，只在数据表加别名。

- 商店/神秘人不是经过生效；只有银行/乐透/送卡格与地面道具经过生效。

- 大地产是路边一整块 2×2，不是两格路。
- 银行只能经过银行格；股票随时可买。
- 现金/存款分离；租金进存款。
