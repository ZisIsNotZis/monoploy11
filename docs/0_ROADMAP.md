# 路线

目标：纯前端、零素材、规则完整的《大富翁 11》复刻；文字/色块棋盘，无后端，任意人数，可结盟，有基础 AI。
预算：¥100 上限；预期现金支出 ¥0（静态托管免费额度）。

每个里程碑都是一个用户能打开、能玩、能判断的竖切片。资料整理不是里程碑，是 M1 的前置工作包。

## 2026-10-29 路线修订

- 原判断：M1 做“一张图 + 1 人类 + 3 AI”的薄切片，AI 与全量系统分开。
- 用户改变：M1 可以只有一张图、几个角色、没有 AI（多人全部玩家操控），但**引擎系统必须做全**；之后里程碑补齐内容，直到完全做出来。
- 代价：M1 变大，AI 推到后面；换来的是不会为了“先能玩”而把系统做成一次性骨架。
- 放弃：M1 的 AI v0；M1 的多地图。

## M1 系统全会跑（单图、热座、无 AI）

一张传统图（骑士庄园）、N 名热座玩家（默认 4，人机混合与队伍划分可配）、无 AI 也可开局；但规则引擎覆盖全部系统：地图图模型与校验器、岔路/死路传送/监狱医院侧路/活动机关板、回合与三槽、48 张卡与合成、商店/研究所、10 位神仙、7 种大建筑、银行/股票/乐透/魔法屋/新闻/神秘人/野狗/乞丐/医院/监狱/载具/物价、1 位领主 × 3 档。内容可以只接几个角色，但每条系统都要有可触发的入口与结算。

- [x] W1.1 资料入库：`docs/data/` → `src/data/*.js`，未证实系数集中到 `src/data/tuning.js`，缺项标 `TODO`。
- [x] W1.2 工程骨架：零依赖 ES Modules + 原生 HTML/CSS，`python3 -m http.server` 即玩；`node --test` 跑单测；无构建步骤。
- [x] W1.3 规则内核：种子 RNG、通用参赛者（控制者/队伍/是否领主）、回合状态机、现金/资产、破产、胜负、槽位、放置物与占位；纯函数，可在 Node 跑。
- [x] W1.4 地图图模型：节点/边/交叉点/侧路/传送/活动板；骑士庄园数据；校验器；SVG/DOM 渲染；逐格移动。
- [x] W1.5 地产闭环：买地、加盖、同街道加成、租金、大建筑占位。
- [x] W1.6 卡片全量：48 张效果解释器、目标选择、响应链、五合一、商店/研究所、手牌 8 张与弃牌。
- [x] W1.7 功能格与遭遇：银行/股票/乐透/魔法屋/新闻/神秘人/野狗/乞丐/医院/监狱/载具/物价。
- [x] W1.8 领主战：1 位领主 × 3 档技能、BOSS 先手、破产结算。
- [x] W1.9 UI 壳：玩家列表（三槽）、棋盘、手牌、日志、行动面板、所有弹层、热座交接。
- [x] W1.10 无头模拟：`node src/sim.js --games 100 --seed 1`，输出胜率与破产原因。

验收：浏览器打开 30 秒内开一局；热座可把一局走到唯一胜者；每条系统至少有一次可触发的演示路径；同一 seed 重跑结果一致；100 局模拟无异常。

## M2 全内容与对手

16 名角色天赋；48 张卡全部接入；10 位神仙；7 种大建筑；4 位领主 × 3 档；16 张图与热斗/抢房；规则型 AI；结盟提议/接受/背叛；魔法屋/新闻/事件全部选项。

验收：每个角色天赋在对应触发下生效；每张卡有获取方式并能结算；每档领主只启用该档技能；16 张图校验器全绿；AI 能独立打完一局；结盟改变租金与胜负判定。

## M3 体验层

目标是“像游戏”，不是“像调试器”：2D 标识/角色头像、角色台词、浏览器 TTS、BGM/音效、金币飞字与数字跳动、骰子/移动/爆炸的轻动效、地图配色、资产榜与新闻横幅、选人/开局界面、快捷键与跳过动画。动画只做 CSS/短过渡，不做逐帧。

验收：关掉素材仍能完整游玩；打开素材有角色辨识度、反馈与节奏；无外部网络请求；移动端可操作。

## M4 平衡与发布

数值调平；README；静态部署；1000 局模拟；发布报告。

验收：公开链接可玩；README 含 30 秒上手与已完成/未完成；1000 局模拟无死锁。

## 记录

- 资料边界：16 角色、16 图、4 领主、48 卡；国服改名版不单独复刻，只在数据表加别名。
- 小游戏：不做，落格折算金钱；折算公式写入 `docs/data/06_SYSTEMS.md`，标为复刻偏差。
- 实时联机：第一版不做；引擎按 N 人本地/热座设计，为将来留位。

## 2026-10 追加（用户口述）
- AI 仅做规则型启发式，不接 LLM。
- 复杂度/效用不划算的功能允许降级：小游戏→随机给钱；其它待评估项在实现前报告。
- 回合：弃到 8 张 → 用卡/操作 → 掷骰 → 移动结算 → 直接换人；掷骰后不再操作。
- 每格最多一个放置物/遭遇物；一格可站多人；每人三槽（神仙/状态/第三槽未定名）。
- 领主战 BOSS 先手；其余按 1..N 循环。
- 地图：无死路（死路末端=无条件随机传送门）；交叉点未停则随机非来路、正好停则可选方向；每图至少一监狱一医院且各有侧路；活动机关板消失时把上面的人移到最近非活动板格；一格多人无副作用。
