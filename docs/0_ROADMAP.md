# 路线

目标：纯前端、零素材、规则完整的《大富翁 11》复刻；文字/色块棋盘，无后端，任意人数，可结盟，有基础 AI。
预算：¥100 上限；预期现金支出 ¥0（静态托管免费额度）。

每个里程碑都是一个用户能打开、能玩、能判断的竖切片。资料整理不是里程碑，是 M1 的前置工作包。

## M1 能走完一局

一张传统图（骑士庄园）、4 名角色（1 人类 + 3 AI）、掷骰、买地、盖房、收租、破产、时间到判资产；文字棋盘、日志、行动面板；固定种子可复现。

- [ ] W1.1 资料入库：把 `docs/data/` 的条目变成可执行数据表（角色/卡/神/建筑/地图/系统），缺数值处标 `TODO`。
- [ ] W1.2 工程骨架：零依赖 ES Modules + 原生 HTML/CSS，`python3 -m http.server` 即玩；`node --test` 跑单测；无构建步骤。
- [ ] W1.3 规则内核：种子 RNG、回合状态机、现金/资产、破产、胜负；纯函数，可在 Node 跑。
- [ ] W1.4 棋盘模型：节点+边+格类型；骑士庄园数据；SVG/DOM 渲染；移动逐格高亮。
- [ ] W1.5 地产闭环：买地、加盖、同街道加成、租金、大建筑占位。
- [ ] W1.6 UI 壳：玩家列表、手牌、日志、行动面板、结算。
- [ ] W1.7 AI v0：买地/留钱/躲高租/结束回合。
- [ ] W1.8 无头模拟：`npm run sim -- --games 100 --seed 1`，输出胜率与破产原因。

验收：浏览器打开 30 秒内开一局；一局能走到唯一胜者；同一 seed 重跑结果一致；100 局模拟无异常。

## M2 卡片、神仙、建筑、魔法屋

48 张卡 + 五合一进阶（数据表口径）；商店/研究所；10 位神仙；7 种大建筑；魔法屋全部选项。

- 卡数据表 + 效果解释器 + 目标选择 + 响应链（无懈/转移）。
- 商店货架/刷新/限购；研究所等级与研发池。
- 神仙附身、请神/送神、天数修正。
- 大建筑等级与功能。
- 魔法屋：先选效果、再随机条件。

验收：每张卡至少一种获取方式并能结算；5 张同名自动合成；魔法屋每个效果可触发；对领主免疫的卡被拒绝。

## M3 经济与遭遇全链

银行利息、股票、乐透、新闻、神秘商人、野狗、乞丐、医院/监狱、载具、物价指数、热斗伤害。

验收：一局中每个系统都能被触发并有日志；物价上涨影响租金与事件金额；股票与乐透有明确的期望值与结算。

## M4 角色、领主、结盟

16 名角色天赋；4 位领主 × 3 档；挑战模式；组队与结盟；AI v1（含结盟判断）。

验收：每个角色天赋在对应触发下生效；每档领主只启用该档技能；领主破产结算队伍资产；AI 结盟决策可复现。

## M5 十六张地图

16 张图拓扑 + 机关 + 热斗/抢房模式；地图数据与渲染分离。

验收：每张图能走通一圈；机关改变连接/功能格；热斗图只有大地产且爆炸扣钱；抢房图开局有建筑。

## M6 AI 与发布

AI v2（估值、威胁、卡组配合、领主针对）；平衡；README；静态部署；发布报告。

验收：公开链接可玩；README 含 30 秒上手与已完成/未完成；1000 局模拟无死锁。

## 记录

- 资料边界：以 16 角色、16 图、4 领主、50 卡为准；国服改名版不单独复刻，只在数据表加别名。
- 小游戏：不做，落格折算金钱；折算公式在实现时写入 `docs/data/06_SYSTEMS.md`，标为复刻偏差。
- 实时联机：第一版不做；引擎按 N 人本地/热座设计，为将来留位。

## 2026-10 追加（用户口述）
- AI 仅做规则型启发式，不接 LLM。
- 复杂度/效用不划算的功能允许降级：小游戏→随机给钱；其它待评估项在实现前报告。
- 回合：弃到 8 张 → 用卡/操作 → 掷骰 → 移动结算 → 直接换人；掷骰后不再操作。
- 每格最多一个放置物/遭遇物；一格可站多人；每人三槽（神仙/状态/载具待证实）。
- 领主战 BOSS 先手；其余按 1..N 循环。
