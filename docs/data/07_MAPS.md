# 地图

本文件记录 12 张地图的设计：主题、拓扑、街区、机关和特殊格。所有地图按同一套同一套规则运行，角色 只作为特殊参赛者出现，不改变地图规则。

## 棋盘模型

棋盘是二维网格，宽、高和格宽由地图数据决定；不同地图可以有不同的尺寸和形状。路面、地产和路面上的东西是三层独立数据：

- **路面**：1×1 可走，`id` 为 `"x,y"`，带 `kind`（空路、银行、商店、新闻、卡片、乐透、魔法屋、税、事件、医院、监狱、传送门、起点）。
- **地产**：小地产 1×1，大地产 2×2；不可走，放在路边，通过正交共边和路面关联。地产没有单独命名和编号，只有内部 id、类型、街区 id。
- **放置物/遭遇物**：每格最多一个，和路面类型、地产互不冲突；角色不占格，一格可以站多名角色。

地产必须至少有一条边贴路，不能出现买不到的孤立地块。街区按物理连接定义：连在一起的小地产和大地产属于同一街区，不管归谁；每簇最多五块，簇间留空，每簇最多一块大地产。大地产提供连通性，但不参与小房屋的街区租金加成。

死路走到尽头原路反弹，不强制传送。传送门只是可选路面类型。初始位置和朝向随机，起始格不触发结算。

## 路面类型

| 类型 | 触发方式 | 效果 |
|---|---|---|
| 空路 | 不触发 | 无 |
| 银行 | 经过或停下 | 打开存取款面板 |
| 乐透 | 经过或停下 | 打开乐透面板，一次一注 |
| 卡片 | 经过或停下 | 获得一张卡片 |
| 商店 | 停下 | 九张卡，最多买三张 |
| 神秘人 | 停下 | 六张卡，最多买两张，每张 1000 |
| 研究所 | 停下 | 六张进阶卡研发 |
| 魔法屋 | 停下 | 六选一 |
| 新闻 | 停下 | 立即结算一条新闻，继续相邻地产 |
| 税 | 停下 | 按物价支付税款 |
| 事件 | 停下 | 触发一条事件 |
| 医院 | 进入 | 住院两回合，出院回到入口 |
| 监狱 | 进入 | 入狱两回合，出狱回到入口 |
| 传送门 | 停下 | 传送到配对传送门 |
| 起点 | 经过 | 领取工资，起始格不触发 |

机关会按地图改变道路连通、开关功能格、打乱障碍物位置。机关状态属于地图数据，不写进 UI；需要时用 `active` 和 `period` 描述。

## 放置物与刷新

每格最多一个放置物/遭遇物。类型包括神仙、野狗、乞丐、神秘人、地雷、炸药、定时炸弹、香蕉皮、果冻墙、陷阱和路障。开局不生成，第三天起按天随机刷新，只刷在空格上；有角色或已有放置物的格子跳过。

## 地图数据契约

每个地图导出：

- `w`、`h`、`cell`：网格尺寸和格宽。
- `nodes`：路面格，含 `id`、`kind`、`x`、`y`、`adjacentPlots`、`active`。
- `edges`：路面正交邻接。
- `plots`：地产，含 `id`、`cells`、`big`、`street`、`level`、`ownerId`、`bigType`。
- `facility`：医院和监狱入口。
- `startId`：起点。

校验器检查：路面连通；每块地产至少一边贴路；街区不超过五块；每簇最多一块大地产；医院和监狱有入口；传送门成对；没有孤立格。

## 验收

12 张地图都能从起点走遍所有路面；所有地产都能从至少一个路面格触发；随机落位不会落在不可走格；死路能反弹；大地产是整块 2×2；地图机关开关后仍保持连通。
