# 大建筑（大型建筑）

状态：INFERRED（二手资料整理；效果文本为游戏内「大型建筑」界面原文）

七种大型建筑：商业中心、大饭店、地产公司、书店、能源中心、研究所、公园。
攻略站只给**定性**效果，**造价与等级 1–5 的具体数值在公开资料里查不到**，凡此类条目一律标【未证实】，
不写估计值。

---

## 大型建筑的通用规则

- 传统地图上，大型建筑与普通地产（住宅 / 连锁店）并存；**同一条街道的房产一起计算租金**，每次停在一处对手房产都会按整条街结算。 [S9]
- 热斗地图上**只有大型地产**，且**大型地产不会受到爆炸（地雷/炸药/飞弹）影响**。 [S5][S6][S9]
- 大型建筑的等级越高效果越强：书店「等级越高，获得卡片的几率越高」、研究所「等级越高，可以研究的卡片就越多」。 [S1][S2]
- 等级上限、升到各级的费用、各等级的数值/触发概率：**【未证实】**（游戏内界面只显示效果说明，不显示造价与概率；
  3DM 的七张界面截图 [S8] 与游侠网/游民星空的文字版 [S1][S2] 同样只有文字说明）。 [S1][S2][S3]
- 大地产的「商业设施项目」可以被变更（改建卡原文：「也可变更大地产的商业设施项目」），即设施类型可换。 [S4]

## 1. 商业中心

- 效果（原文）：商业中心可以向停留在此的对手收取租金，收取的数目就由**转盘**来决定。 [S1][S2][S3]
- 租金规则：停在此格的对手付租，**金额由转盘随机决定**，不是固定值。 [S1]
- 各等级转盘区间 / 租金数额：**【未证实】**。

## 2. 大饭店

- 效果（原文）：大饭店虽然收取的租金**较少**，但可以**强行使对手住店度假**，为你争取时间。 [S1][S2][S3]
- 租金规则：租金低于其他大建筑；核心价值是**强制对手住店度假**（行动封锁）；
  强制住店的**天数**与租金系数：**【未证实】**。 [S1]

## 3. 地产公司

- 传统：**降低己方应付租金的数额**。 [S1][S2]
- 热斗：**降低己方承受的爆炸伤害**。 [S1][S2]
- 规则要点：这条对**己方**（含队友，原文措辞「己方」）生效，属防御型建筑，不是对对手收钱的建筑。 [S1]
- 减免比例（按等级）：**【未证实】**。

## 4. 书店

- 效果（原文）：我方成员**离开商店和神秘人**时，有机会额外获得 **1～3 张**卡片；**书店等级越高，获得卡片的几率越高**。 [S1][S2][S3]
- 触发条件：己方角色「离开商店」或「离开神秘人」时结算（不是踩到书店时结算）。 [S1]
- 有资料补充「队友越多效果越好」[S3]，即按己方成员数量多次触发。
- 各等级的**触发概率**与 1/2/3 张的分布：**【未证实】**。

## 5. 能源中心

- 效果（原文）：可以**增加对手购买卡片的花费**；当你**停留在此时，你将获得巨额收入**。 [S1][S2][S3]
- 规则要点：两条独立效果——对对手是涨价（买卡变贵），对自己是踩到即得钱。 [S1]
- 「巨额收入」的具体数额、对手买卡的加价比例、各等级数值：**【未证实】**。

## 6. 研究所

- 效果（原文）：研究所的**等级越高，可以研究的卡片就越多**，在研究所中选择想要研究的卡片。 [S1][S2][S3]
- 规则要点：研究所是**卡片研发点**，可自选要研究的卡片；等级决定可选卡池大小。 [S1]
- 各等级开放的卡片清单：**【未证实】**。

## 7. 公园

- 效果（原文）：公益设施，公园可以用来**跳广场舞**，利国利民的公益设施。 [S1][S2][S3]
- 规则要点：**公益设施**，公开资料里没有给出收租或加成的数值；除文本描述外无其他机制说明。 [S1]
- 是否有隐藏效果：**【未证实】**。

## 被改建 / 被摧毁的规则

公开资料中没有列出独立于卡片/神仙的大建筑拆迁规则；已知的改建与降级入口只有下列几条，均为原文：

| 卡片 | 原文效果 | 对大建筑的作用 |
|---|---|---|
| 改建卡 | 将住宅改建为连锁店，或将连锁店改回住宅。**也可变更大地产的商业设施项目**。 | 可以**换掉大建筑的设施类型**（具体可换范围原文未列，例如商业中心 ↔ 大饭店属**推断**）[S4] |
| 工程车卡 | 驱使工程车**拆除周围 1 层**房屋。 | 对建筑**降 1 层**（层数归零后是否变回空地，原文未写明；【未证实】）[S4] |
| 怪兽卡 | 召唤火龙喷出炽焰，**毁坏指定街道所有房屋 1 层**。 | 对**整条街**的每处建筑各降 1 层 [S4] |
| 天使（神仙） | 传统：走到任何地产格，都会令该地建筑**免费加盖 1 层**。 | 对经过的大建筑升 1 层 [S7] |
| 恶魔（神仙） | 传统：走到任何地产格，都会令该地建筑**下降 1 层**（空地不会被破坏）。 | 对经过的大建筑降 1 层 [S7] |

补充：

- **热斗地图上的大型地产不受爆炸影响**，因此地雷卡 / 炸药卡 / 飞弹卡不能摧毁大地产。 [S6][S1]
- 传统地图的大地产是否可以「整栋拆除」：公开资料无原文，**【未证实】**（现有证据只支持逐层下降）。

## 缺口（进入实现前需要实测/解包的数值）

1. 七种大建筑各自的**造价**与**升级到 2/3/4/5 级的费用**。
2. 商业中心的转盘档位与各档金额。
3. 书店各等级的触发概率、额外卡片 1–3 张的分布。
4. 地产公司各等级的租金/爆炸伤害减免百分比。
5. 能源中心各等级的收入额与对手买卡加价比例。
6. 研究所各等级开放的卡片清单。
7. 公园是否存在收租或隐藏加成。
