# 神仙

神仙分两种生效时机，本文件逐条区分：
- **「附身时」** = 附身发生的**一次性**结算（例如财神立刻向每位对手收一次钱）。
- **「附身期间」** = 附身持续期内的**持续**效果（例如财神的免租）。


---

## 十位神仙效果

### 1. 财神

- 传统：附身时，向每位对手收取**大量**的现金。附身期间，**免除缴纳租金等费用**。
- 来源 [S1][S2][S3]（三站文本一致，数值「100%」为原文）

### 2. 穷神

- 传统：附身时，向每位对手**赠送**大量的现金。附身期间，租金等费用**增加 100%**。
- 来源 [S1][S2]

### 3. 福神

- 传统：附身时，获得 **2 张**随机卡片。附身期间，停留在己方地产时，**免费加盖 1 层**建筑。
- 来源 [S1][S2]

### 4. 衰神

- 传统：附身时，**随机遗失 2 张**卡片。附身期间，走到己方地产**不可加盖**。
- 来源 [S1][S2]

### 5. 天使

- 传统：附身期间，走到**任何**地产格，都会令该地建筑**免费加盖 1 层**（己方与对手的地产都加）。
- 来源 [S1][S2]

### 6. 恶魔

- 传统：附身期间，走到任何地产格，都会令该地建筑**下降 1 层**（**空地不会被破坏**）。
- 来源 [S1][S2]

### 7. 土地公

- 传统：附身期间，走到**非己方**地产格时，**将该地占为己有**。
- 来源 [S1][S2]

### 8. 糊涂神（通用）

- 附身期间，**每次前进随机转向**；**使用卡片可能失败**（失败**不退还**卡片）。
- 失败概率定稿。
- 来源 [S1][S2]

### 9. 武神（通用）

- 附身期间，**所有卡片的使用范围增加 3 格**。
- 来源 [S1][S2]

### 10. 凶神（通用）

- 附身期间，**部分地格对自身无效**（游戏内原文只写「部分地格」，具体清单定稿）。
- 来源 [S1][S2]

## 附身持续天数

- **基础附身天数 3 天。**
- 可确证的是「存在一个按**天**计的附身时长」，因为它被角色天赋以「天」为单位增减：

| 角色 | 天赋 | 对神仙时长的作用 |
|---|---|---|
| 宫本宝藏 | 耍酷 | 所有神仙附身时间 **+1 天** |
| 阿土伯 | 天命 | 土地公附身时间 **+3 天** |
| 金贝贝 | 天真 | 财神和福神的附身时间 **+3 天** |
| 孙小美 | 杂技世家 | 武神附身时间 **+10 天** |
| 忍太郎 | 幻术 | 天使和恶魔的附身时间 **翻倍** |

（来源 [S4][S5]）

孙小美「杂技世家」采用「武神附身时间 **+10 天**」；其余八条天赋按表执行。

## 请神 / 送神规则

- **请神卡**（通用）：请来**最靠近自己身边**的神仙。 [S6]
- **送神卡**（通用）：送走**周围角色**身上的神仙**或定时炸弹**。 [S6]
- 神仙还可以从地图上的神仙格和事件获得。
- 同一角色身上同时只携带一位神仙（由送神卡「送走身上的神仙」的措辞可推知，机制细节定稿）；
  神仙槽与定时炸弹共用同一槽、且能被粘身道具顶掉——见 `02_BOSSES.md`「角色槽位与行动顺序」。
- 有 BOSS 时，BOSS 开局会主动请神——游民星空攻略里把「让他请到财神」当作拖慢 BOSS 发育的手段。 [S7]

### 与神仙相关的角色天赋（免疫 / 反制）

| 角色 | 天赋 | 效果 |
|---|---|---|
| 莎拉公主 | 随心所欲 | **免疫**衰神和穷神 |
| 莎拉公主 | 香车美人 | **免疫**糊涂神和凶神 |
| 金贝贝 | 乐园规则 | 自身回合外，**不能成为对手送神卡的目标** |
| 钱夫人 | 公关 | 神仙附身期间，**不能成为拾取卡和查账卡的目标** |
| 宫本宝藏 | 剑道 | 神仙附身时，获得 1 张送神卡；送神卡使用距离翻倍 |
| 忍太郎 | 忍术 | 神仙附身时，获得 1 张机器娃娃卡 |

（来源 [S4][S5]；「免疫」= 该神仙不能附身到该角色身上）
