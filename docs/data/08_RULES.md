# 规则

本文件记录一局游戏从开局到结束的规则。所有地图、所有参赛者使用同一套规则；BOSS 只是带三档技能的特殊参赛者，不另立规则。

## 人数与队伍

一局可以有任意 N 名参赛者，默认四名。每名参赛者独立配置人类或 AI、队伍、颜色、是否 BOSS。全人类、全 AI、人机混合都合法。队伍可以任意分组：每人一队、所有人一队、BOSS 单独一队都可以。

每名普通角色有两个天赋；BOSS 按难度启用一到三个技能。先手按座位顺序；有 BOSS 时 BOSS 先手。队伍总资产最高者获胜；BOSS 破产时 BOSS 方直接失败。

## 开局

所有人随机落在不同路面，随机朝向。起始格不触发结算，不自动买地，不收租。初始现金、存款、手牌数、物价周期、天数上限都是开局参数。

地图上所有地产开局为空地，BOSS 也不例外。买下小地产只得到空地面，下一次停到旁边才建第一层；买下大地产只得到大空地，下一次投资才选大建筑。

## 回合

回合顺序固定：

1. 手牌弃到八张（BOSS 天赋可提高上限）。
2. 可以使用卡片、银行和股票。
3. 掷骰并移动。
4. 按落点顺序结算。
5. 换下一名参赛者。

掷骰后不能再使用卡片、买卖股票或存取款。银行存取在银行面板里完成，不结束移动。

## 移动

步行一颗骰，机车两颗，汽车三颗。沿路面正交邻接逐格移动，每格结算一次经过事件。经过交叉点未停下时随机选非来路方向；正好停在交叉点则等落点结算完再选方向。死路原路反弹，继续剩余步数。传送门是可选路面类型，不承担死路出口。

移动结束且没有待选方向时，朝向固定为前方非来路方向。医院和监狱是侧路，进入后按回合数停留，出来回到入口。

## 落点顺序

1. 脚下的路面上的东西：道具、神仙、野狗、乞丐、神秘人。
2. 路面类型：卡片、银行、乐透、商店、魔法屋、新闻、税、事件、传送、医院、监狱。
3. 所有相邻地产：对手收租，队友免租，自己的地产可加盖或选大建筑，无主地产逐块询问买不买。
4. 事后神：福神、天使、土地公、凶神。
5. 如果停在交叉点，选择方向。

经过但不停下只触发银行、乐透、送卡格和地面道具；商店、神秘人、魔法屋、新闻必须停下。新闻停下后立即结算，然后继续相邻地产。

## 手牌与卡片

手牌上限八张；超过八张只在本人回合开始时弃牌。同种卡凑满五张自动合成进阶卡。卡片分主动、被动响应和进阶；被动卡灰色不可主动使用，只在对应时机询问。

卡片目标分自身、角色、地块、街区和全场。对地面卡点地产，街道卡点任意街区地产，放置卡点路面，角色卡点角色。范围默认五步，机器娃娃十步，遥控骰子按载具范围。

五合一配方六组：飞弹→急速弹、涨价→辉煌、停业→窘困、送神→绿化、怪兽→灾祸、请神→神眷。

## 地产与租金

小地产 1×1，大地产 2×2，都不可走。地产至少一边贴路。街区按物理连接定义，连在一起的小地产和大地产同一街区；每簇不超过五块左右，每簇最多一块大地产。

租金只数同一所有者、同一街区里已经建成的小房屋；空地面和大地产不算。大地产只提供连通性和自身建筑效果。买地用现金，租金进房东存款。

破产时地产不删除建筑，只清空归属；别人再买下时保留原层数和建筑类型。

## 银行、股票、乐透

现金和存款分离。买地、买卡、买股票、买乐透、纳税和罚款只用现金；租金进存款；存款按周期结息。经过或停在银行打开存取款面板，存取不结束移动。

股票随时可以买卖，不依赖股票格。乐透号码 1–30，同一期全场唯一，一次访问只能买一注；按期开奖，无人中奖时奖池累计，票和已售号码保留，中奖后清空并重置。

## 三槽状态

每名参赛者有三个持续状态槽：

- **绑定槽**：神仙、定时炸弹，带剩余天数。
- **人物槽**：乌龟、梦游、冬眠、冰冻、停留，带剩余天数。
- **物理槽**：监狱、医院，带剩余回合数。

同槽新状态顶替旧状态。梦游、冬眠跳过回合；乌龟每次只能走一步；冰冻把点数视为零并原地再触发一次落点。

## 胜负

天数上限到达时，队伍总资产最高者获胜。资产等于现金、存款和地产估值之和。现金不足以支付时破产，破产者退出对局；BOSS 破产时 BOSS 方失败。只剩一队时该队获胜。
