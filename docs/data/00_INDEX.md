# 数据索引

本目录是 `docs/3_REQUIREMENT.md` 的内容附录：角色、角色技能档位、卡片和地图。所有可调数值由开局配置提供，本目录只记录内容条目和结构，不固定初始资金、手牌上限、价格或概率。

## 文件

| 文件 | 覆盖 |
|---|---|
| `01_CHARACTERS.md` | 16 名角色、每人两个天赋 |
| `02_ROLE_TIERS.md` | 4 名角色 × 3 档技能 |
| `03_CARDS.md` | 48 张卡（含 6 张进阶）、五合一、目标、限制与槽位 |
| `07_MAPS.md` | 12 张地图、机关、图块与刷新、数据模型 |

## 固定口径

- 每名参赛者选择一个角色；角色数据决定技能和技能档位。
- 地图尺寸、路线、街区和机关由地图数据决定；不同地图可以不同尺寸。
- 卡片、神仙、大建筑、状态和事件的规则写在 `docs/3_REQUIREMENT.md` 正文；本目录只列内容。
- 所有金额、概率、天数、倍率、上限和初始值都是配置项，不写死在内容表里。
- 初始位置和朝向随机，起始格不触发；死路原路反弹。
- 商店、神秘人、魔法屋、新闻只有停下才触发；银行、乐透、送卡格和地面道具经过时触发。

M1 使用 `src/data/maps/grid-manor.js` 的自设计网格图；M2 把 12 张地图按同一套网格模型展开。
