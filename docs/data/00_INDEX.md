## 已确认的硬事实（可直接用于实现）

- 角色 16 位（14 首发 + 路德维希 + 十一）；十一的天赋是**随意门卡→超级骰子卡**、**免费卡→遥控骰子卡**，不是传送门卡。
- 领主 4 位，各 3 档；困难档共 3 个技能；圆圆的三个技能是聚集 / 大收益 / 流通手段。
- 卡片总数 **48**（含 6 张进阶），不是 50；五合一配方 6 组：飞弹→急速弹、涨价→辉煌、停业→窘困、送神→绿化、怪兽→灾祸、请神→神眷。
- 神仙 10 位；大建筑 7 种；地图 16 张（12 传统 + 4 热斗）；抢房是规则变体，不是第 17 张图。
- 手牌上限 8 张（领主天赋可到 16）；回合开始弃牌；掷骰结算后回合结束。
- 一格可站多人；一格最多一个放置物/遭遇物；每人三槽（神仙/状态/第三槽未定名）。
- 领主战 BOSS 先手；其余按 1..N 循环。
- 对领主无效：查账、均贫、魔术、均富；章鱼王额外免疫拾取卡。
- 货币只有现金，点券已取消；股票只在单机自由赛。

## 关键缺口（按影响排序）

1. **钱的全部系数**：地价、建房/加盖费、同街道租金倍率、等级倍率、物价曲线、月息、股票、乐透、事件金额。公开资料只有零星样本（如连锁店基础租金 2500×物价；开局 10 万/12 万；月息 10%）。
2. **6 张地图的拓扑**：狂欢节、音乐之都、锦绘时代、天使岛、火山古迹、糖果大战、玩具派对、深海弈斗（其中 3 张只有名字）。
3. **逐卡价格与获取池**：商店无公开价目表；研究所/神秘人/事件池无清单。
4. **概率**：各“一定几率”“大幅”的确切值；神仙附身基础天数；机关周期。
5. **槽位**：第三槽的官方定名与内容（载具可能性偏弱，需实机）。

## 实现口径

- 所有未证实系数集中到一张可调常量表，默认值写“社区样本/合理近似”，并在代码注释与 README 标明不是原版。
- 已证实的效果优先按原文实现；效果文本本身模糊的（如“一定几率”）用可配置概率。
- 数据文件是给人和 agent 读的；下一步转成 `src/data/*.js` 时保持同名字段，避免二次解释。
