# 目标

状态：EXPLICIT + CONFIRMED（用户逐轮确认；最近一次口径以 2026-10-29 的网格棋盘与三层模型为准）

## 一句话

做一个纯前端的《大富翁 11》规则复刻：保留原版的核心机制、角色/领主/卡片/神仙/建筑/经济系统与信息，表现层用方形图块、图标占位和文字代替 3D 美术；单页 Web、无后端、离线可玩。棋盘是一张网格，路面、路边地产、路面上的东西是三层互不冲突的层；人数、队伍、人机混合、领主由谁操控都可配置。小游戏不做，直接折算成钱；数值未知处用集中可调近似值，不假装逐值还原。

## 用户明确要的

- 核心逻辑与信息尽量和原版一致；保不一致时按性价比取舍，不为“逐值还原”牺牲可玩性。
- 角色天赋、领主三档、48 张卡与五合一、10 位神仙、7 种大建筑、商店/银行/股票/乐透/魔法屋/新闻/野狗/神秘人/乞丐、地产与金钱计算，都要有。
- 地图至少拓扑/关系等价；最终实现采用“网格棋盘 + 路面/地产/放置物三层”，而不是先画拓扑再塞格子。
- 至少 4 个正常角色 + 1 个 BOSS；人数不写死，支持任意 N、全人类、全 AI、混合、任意组队。
- 支持结盟；AI 只做规则型启发式，不接 LLM。
- 纯前端、无后端、无账号、无联网、无手柄；本地热座多人交替操作。
- 美术/语音/音乐不是永久砍掉：2D 图标、头像、台词、浏览器 TTS、BGM 作为后期体验层；3D、剧情、成就、装扮永久不做。
- 小游戏、逐帧动画、股票 K 线、隐藏系数逐帧反推：不做/近似。

## 优先级

1. 规则闭环与三层棋盘模型正确（走、停、经过、买、租、结算顺序）。
2. 一局能从随机开局走到胜负；热座可完整操作。
3. 内容覆盖：角色、卡、神、建筑、领主、地图、事件。
4. 表现与操作紧凑清晰，不干扰地图。
5. 成本：零付费素材、零后端、零构建依赖。

## 模式

有限目标：做到“规则完整、可玩、可发布”后收口；之后迭代体验层与更多地图/内容。

## 已定死的产品口径

- 棋盘是网格，不先画图拓扑；路面 1×1 可走，地产 1×1 或 2×2 不可走，路面上的东西每格最多 1 个。
- 地产可以贴着路，也可以在外圈路的外侧；所有小地产必须至少一边贴路，大地产整块贴路。
- 同一条街的连续地产最多 5 块左右，中间用空断开；每簇最多 1 块大地产。
- 初始位置与朝向随机；初始格不触发结算。
- 回合：弃到 8 张 → 用卡/银行/股票 → 掷骰 → 移动 → 脚下 item → 路面类型 → 相邻地产 → 方向。
- 死路反弹，不强制传送；传送门只是普通路面类型。
- 只有银行、乐透、送卡格是“经过生效”；商店/神秘人/魔法屋/新闻必须停下。
- 现金与存款分离：购买只用现金，租金进存款，存款吃利息。
- 大地产先买空地，第二次投资才选 6 种建筑之一；公园只能被改建卡改成。
- UI：无顶栏；右侧落地侧栏（约 390px），上方状态、中间日志、底部情境区；无重开/银行按钮；股票按钮常驻。
