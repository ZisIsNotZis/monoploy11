# 目标

状态：EXPLICIT（来自用户需求原话，尚未逐条确认）· 里程碑为 INFERRED

## 一句话

做一个纯前端的《大富翁 11》规则复刻：核心逻辑与信息与原版一致——16 名角色天赋、4 位领主 × 3 档难度、48 张卡片与五合一进阶卡、10 位神仙、7 种大建筑、商店/银行/股票/乐透/魔法屋/新闻/野狗/神秘人/乞丐、地图拓扑与机关、4 人 + 1 领主的挑战模式与任意人数自由赛、结盟与基础 AI。表现层以 2D 色块与文字为主，可后补 2D 标识、角色台词、浏览器 TTS、BGM；无 3D、无逐帧动画。单页 Web、无后端，小游戏直接折算成钱。

## 用户明确说过的

- 所有游戏核心逻辑、信息保持不变；UI/美术/音乐/语音越简单越好，甚至用文字替代。
- 地图路线要一样，至少拓扑等价；画得简单可以。
- 不能少：每个人物技能、占卜屋（魔法屋）所有选择、事件所有选择、所有卡片、所有神、狗、神秘商人、商店、彩票、股票、所有 BOSS 三档难度的不同特性、大建筑类型与功能、所有金钱计算逻辑。
- 小游戏可以不要，直接换成算钱。
- 至少 4 个正常角色 + 1 个 BOSS；人数不必写死，任意数量都应支持。
- 支持结盟，有基础 AI，AI 不能白吃。
- 纯前端，不需要后端；框架自选。

## 优先级

1. 规则与数值完整（少一条都算没达标）。
2. 一局能从头走到胜负，AI 有基本常识。
3. 地图拓扑等价（能复刻几张是几张，先保证路线关系）。
4. 表现与操作（文字/色块即可）。
5. 成本（零素材、零后端、零付费依赖）。

## 模式

有限目标：以“规则完整、可玩、可发布”的最后里程碑收口；之后按需迭代地图与 AI。

## 尚未确认（见 frontier）

- “所有资料”的边界：是否包含国服改名版、DLC 角色、领主战后加的圆圆/小熊与 16 图。
- 结盟是原版组队，还是额外加的外交/背叛机制。
- 地图拓扑接受“近似等价”还是必须逐格一致。
- 数值未知处用估计值还是留空。
