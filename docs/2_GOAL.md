# 目标

这个项目要做的是一个纯前端的《大富翁 11》规则复刻：原版的核心信息与规则链尽量保留，表现层则收成一张二维网格棋盘、方形图块、图标占位和文字。它打开就是可玩的一局，不需要后端、账号、构建步骤或联网请求；人数、队伍、人机混合和领主由谁操控都能配置。原版的小游戏不做，落格直接折算成钱；原版没有公开的系数不假装精确，统一收进可调近似值。

它要保留的是角色与天赋、领主及三档难度、卡片与五合一进阶、神仙、大建筑、地产与租金、现金与存款、银行、股票、乐透、商店、魔法屋、新闻、野狗、乞丐、神秘人和医院监狱这一整套系统，而不是只做一个能掷骰买地的简化大富翁。地图不追求逐格照抄原版，但路线关系、模式差异和机关要保留；M1 先用一张自设计的网格图把所有系统跑通，之后再把原版地图按同一套网格模型重画。

优先级依次是：规则闭环与结算顺序正确；一局能从随机开局走到胜负；内容覆盖完整；操作与显示紧凑清晰；成本保持零付费素材、零后端、零构建依赖。美术、语音和音乐不是永久砍掉，它们属于后期的体验层：2D 标识、头像、角色台词、浏览器 TTS、BGM 和轻量 CSS 动画可以后补；3D、剧情、成就、装扮、逐帧动画和股票 K 线不做。

已经定死的产品口径是：棋盘是一张网格，路面 1×1 可走，地产 1×1 或 2×2 放在路边且不可走，路面上的东西是独立的第三层，每格最多一个；小地产必须贴路，大地产是一整块 2×2，不是两格路；同一条街的地产连成不超过五块左右的簇，簇间留空，每簇最多一块大地产。所有人随机位置、随机朝向，起始格不触发结算。回合按弃牌、用卡与银行股票、掷骰、移动、结算、换人的顺序推进，结算顺序固定为脚下东西、路面类型、相邻地产、方向。死路原路反弹，不强制传送；只有银行、乐透、送卡格和地面道具在经过时生效，商店、神秘人、魔法屋、新闻必须停下。购买只用现金，租金进入房东存款，大地产先买空地再选六种建筑之一，公园只能由改建卡产生。界面只保留右侧落地侧栏：上方状态、中间日志、底部情境区；没有顶栏、底栏、重开按钮和银行按钮，股票按钮常驻。

长期不做的内容也固定下来：小游戏、3D、剧情、成就、装扮、实时联机、账号、匹配、手柄、互联网功能、逐帧动画、股票 K 线，以及对隐藏系数和资料不足地图的逐格反推。可玩性和规则闭环优先于“逐值还原”。
