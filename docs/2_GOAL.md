# 目标

Monopoly 11 是一款纯前端的回合制棋盘游戏：玩家轮流掷骰、沿道路移动、买地、建房、收租、使用卡片、经营现金和存款，最后按队伍总资产或破产结果决出胜负。它打开就是可玩的一局，不需要后端、登录、构建步骤或联网请求。

一局至少有 2 名参赛者，没有人数上限。每名参赛者独立选择人类或 AI、队伍、颜色；全人类、全 AI、人机混合都合法。一局中至多一名参赛者可以是 角色；角色 只是初始配置和技能不同的特殊参赛者，有三个档位，和所有人一起排队、掷骰、买地、收租、破产。所有地图使用同一套规则。

游戏包含角色与天赋、角色 及三档技能、48 张卡与五合一进阶、10 位神仙、7 种大建筑、地产与租金、现金与存款、银行、股票、乐透、商店、魔法屋、新闻、野狗、乞丐、神秘人、医院和监狱。

棋盘固定为网格：路面 1×1 可走，地产 1×1 或 2×2 放在路边且不可走，路面上的东西是独立的第三层，每格最多一个；小地产必须贴路，大地产是一整块 2×2，不是两格路；同一条街的地产连成不超过五块的簇，簇间留空，每簇最多一块大地产。所有人随机位置、随机朝向，起始格不触发结算。

优先级依次是：规则闭环与结算顺序正确；一局能从随机开局走到胜负；内容覆盖完整；操作与显示紧凑清晰；成本保持零付费素材、零后端、零构建依赖。美术、语音和音乐属于后期体验层：2D 标识、头像、角色台词、浏览器 TTS、BGM 和轻量 CSS 动画可以后补，缺素材时退化为文字。

界面固定为右侧落地侧栏：上方状态、中间日志、底部情境区；没有顶栏、底栏、重开按钮和银行按钮，股票按钮常驻。所有选择在右侧栏完成，空间目标回到地图点击。金额、卡片和状态变化以飘字显示在角色头顶。

完整规则以 `docs/3_REQUIREMENT.md` 为准。
