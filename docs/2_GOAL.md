# 目标

这个项目要做的是一个纯前端的《大富翁 11》规则复刻：原版的核心信息与规则链完整保留，表现层收成一张二维网格棋盘、方形图块、图标和文字。它打开就是可玩的一局，不需要后端、登录、构建步骤或联网请求。

一局可以有任意 N 名参赛者，每名参赛者独立选择人类或 AI、队伍和颜色；全人类、全 AI、人机混合都合法。BOSS 不是另一种玩法，只是一名带三档技能的特殊参赛者，人类也能操控；它和普通角色一起排队、掷骰、买地、收租、破产，差别只在技能强度和初始配置。地图统一遵循正常对局规则，不做另一套地图规则。

它要保留的是角色与天赋、BOSS 及三档技能、卡片与五合一进阶、神仙、大建筑、地产与租金、现金与存款、银行、股票、乐透、商店、魔法屋、新闻、野狗、乞丐、神秘人、医院和监狱这一整套系统，而不是只做一个能掷骰买地的简化大富翁。

棋盘固定为网格：路面 1×1 可走，地产 1×1 或 2×2 放在路边且不可走，路面上的东西是独立的第三层，每格最多一个；小地产必须贴路，大地产是一整块 2×2，不是两格路；同一条街的地产连成不超过五块左右的簇，簇间留空，每簇最多一块大地产。所有人随机位置、随机朝向，起始格不触发结算。

优先级依次是：规则闭环与结算顺序正确；一局能从随机开局走到胜负；内容覆盖完整；操作与显示紧凑清晰；成本保持零付费素材、零后端、零构建依赖。美术、语音和音乐属于后期体验层：2D 标识、头像、角色台词、浏览器 TTS、BGM 和轻量 CSS 动画可以后补，缺素材时退化为文字。

界面固定为右侧落地侧栏：上方状态、中间日志、底部情境区；没有顶栏、底栏、重开按钮和银行按钮，股票按钮常驻。所有选择在右侧栏完成，空间目标回到地图点击。金额、卡片和状态变化以飘字显示在角色头顶。
