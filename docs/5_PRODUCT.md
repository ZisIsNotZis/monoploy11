# 产品

## 形态

它是一张打开的桌面：左边是网格棋盘，右边是落地侧栏。没有登录、没有后端、没有外部素材请求；所有视觉由方形图块、图标、颜色和简短文字组成。打开页面就能开一局，棋盘和侧栏是同一个界面的两半，不靠弹窗切换。

## 信息架构

右侧栏是唯一的信息与操作面板，宽度默认 390px，左边框可以拖动调整；侧栏正文按 13–15px 显示，保证不是小字堆。顶部固定显示天数、物价和股票按钮；下面是玩家状态，每名角色用一行式自动换行显示头像、角色、队伍、现金、存款、位置、朝向和三个持续状态槽：绑定（神/定时炸弹）、人物（乌龟/梦游/冬眠/冰冻）、物理（监狱/医院），每槽带图标和倒计时；中间是日志，占满剩余高度并自动滚到底；底部是情境区，平时放骰子和手牌，需要选择时整块切换成买地、方向、大建筑、商店、乐透、银行、股票、魔法屋、神秘人或卡片目标面板。所有选择都在这个底部区域完成，不另开居中大弹窗。

棋盘尺寸由地图数据决定；路面 1×1，小地产 1×1，大地产是地图定义的整块矩形（默认 2×2）。地图里不写文字，路面、地产和大建筑用图标；tooltip 挂在具体图片上，不在格子上拼一段总描述。空路面没有图标，也就没有提示。人物行本身带技能 tooltip。路面上的东西最多一个，和路面类型同时存在时两个图标叠放。人物是带方向指针的圆，当前角色高亮，指针始终指向前方。

## 三层文档的分工

本文是**体验设计**，回答“玩家看到、听到、感到什么”。玩法规则在 `3_REQUIREMENT.md`，架构在 `9_IMPLEMENTATION.md`。

- 玩法设计：回合、移动、经济、卡牌、角色、神仙、地图原语的结算。
- **体验设计：本文。** 界面、地图编排、图标、字体、颜色、动效、字幕、语音、对话气泡、AI 节奏、等待时间、信息密度。
- 架构设计：文件分层、状态结构、地图 schema、地图运行时、UI 接口、测试。

地图设计属于体验设计：地图主题、路线编排、初始建筑、机制组合、节奏和玩家感受都放本文；地图能用的规则原语放 `3_REQUIREMENT.md`，地图数据结构和运行时放 `9_IMPLEMENTATION.md`。

## 本次地图：大酒店

12 张地图已进入当前版本：大酒店是默认图，其余 11 张各有独立机制。

### 大酒店

- **空间**：27×19。外圈是安全但慢的收租路；中央是一个 3×3 的大酒店，外面围一圈路；四条放射路把外圈和内环连起来；四角各有一个小环路和一块 2×2 大地产，至少两块被三条路包住，形成 6 个邻接路面。
- **中心**：大酒店占 3×3，四周 12 个路面格都与它相邻。任何人从任何方向靠近中心，都可能踩到同一块地。
- **开局**：大酒店是 Lv.3 的无主已建大饭店，标价 90,000；四角有两块无主已建商业/饭店 Lv.2；外圈散布无主 Lv.1–2 小房屋。买下前不产生租金，买下后继承等级和类型。
- **签名机制**：中心大酒店是全场最贵的资产，也是全图最容易踩中的地。抢到它的人会立刻改变租金结构；没抢到的人可以走外圈低租金路线，或用卡片、股票和事件翻盘。
- **体验目标**：第一圈看见中心，第二圈开始算“要不要赌中心”，第三圈已经有人因中心租金改变策略。

### 地图视觉

- 中央 3×3 大酒店必须画成一整栋建筑，不能画成九宫格；四周环路把建筑包起来，12 个邻接格用金色细边提示“这里会触发大酒店”。
- 四角 2×2 大地产画成一整块，和中心形成尺度差；小房屋用不同层高区分 Lv.1–5。
- 初始无主建筑用中性边框加“无主”角标；被买下后换成队伍色边框。
- 医院、监狱、传送门、商店、银行、卡片、魔法屋在边缘有固定位置；地图不写文字，靠图标和 tooltip。

### 地图节奏

中心大酒店不能在开局 30 秒内被买走，也不能永远没人买。首圈让玩家看见它，第二圈出现第一次购买机会，第三圈租金开始影响路线。若到第 10 天仍无人买，AI 或事件应主动推动一次中心交易。

## 地图体验

12 张地图不是同一张图的换色。每张地图有一个签名机制，改变路线、时间、估值或初始局面；机制必须能被玩家从地图和日志看出来。地图不靠新增一种道具来制造差异；狗群、爆炸、洪水、熔岩改变的是路线和风险，不是换一张图标。

### 地图视觉

- 地形表面画在路面底色或边缘：冰面、积水、熔岩、云桥、坡道各有纹理和颜色，不占放置物层。
- 初始联排房屋直接按建筑 SVG 画在地产格里；无主建筑用中性边框，中立地标用独立徽章和 tooltip。
- 关闭的边画断口；单行道画箭头；区域加成用地块边缘色，不刷满整格，避免遮住图标。
- 地图规则状态显示在侧栏顶部：当前天气、下一次喷发、开启的桥、当前巡游区、当前季节；大酒店当前把“中心 无主/所有者 Lv.”放在顶部。
- 只有狂欢节使用四象限色块表示当天加成区；大酒店不使用装饰色块。路面用细连接线连成路径，避免看起来像一排孤立方块。
- 地图选择界面显示地图缩略图、主题、初始局面和一句机制说明；不写规则长文。

### 地图节奏

每张地图的第一圈要让玩家看到它的签名机制，第二圈让机制影响一次买卖或路线，第三圈让玩家开始利用或规避。地图不允许把机制藏在 tooltip 里，也不允许第 10 天才第一次出现核心机关。

## 视觉语言

整体是深色底、低饱和面板和金色强调。路面用单字图标，例如银行是“银”、商店是“店”、新闻是“新”、卡片是“卡”、乐透是“彩”、魔法屋是“魔”、税是“税”、事件是“事”；空白路面不画图标，只留底色和边框，让放置物出现时能占满整格。地形表面作为底色或边缘纹理叠加在路面上：冰面、积水、熔岩、云桥、坡道不另画成放置物。初始联排房屋直接按建筑 SVG 画在地产格里，不写成文字说明；中立地标用独立徽章和 tooltip 区分。地产用“地”，大地产用“大”，建好后用建筑首字；有主地产用归属色边框和淡底色。地产没有单独命名或编号，界面上只有“小地产/大空地”；等级、租金和建筑效果不直接写在地图上，放在 tooltip 和后续美术里。

卡片和商店卡都是方形卡面：卡面里放一个字或图形，商店在卡面下只显示价格，不写卡名和效果。地块颜色按二维语义区分，但整体压低饱和度：路面停下用实线偏暖灰，路面经过用虚线偏冷灰；障碍物停下用实心、较亮的图标，经过用更暗、更透明、虚线边框的图标。玩家的队伍色才是高饱和主色，同队同色相、队员靠明暗区分。大地产不画内部四格，人物不画身体，只画带方向指针的圆。金额变化用大号正负数字浮在角色头顶并淡出，颜色区分收入和支出。

## 交互

回合按弃牌、用卡与银行股票、掷骰、移动、结算、换人的顺序推进，掷骰后不能继续操作。落点结算顺序固定为脚下东西、路面类型、相邻地产、事后神、方向。经过银行、乐透、送卡格和地面道具会触发；经过商店、神秘人、魔法屋和新闻不会，必须停下才触发；新闻停下后直接结算并继续处理相邻地产，不额外要求点击。多块相邻无主地逐块询问，买或放弃后继续下一块；大地产六选一；公园只能由改建卡产生。

停在魔法屋时，底部情境区整块换成六项效果：随机请神、获得三张卡片、随机摧毁建筑、全部存入银行、随机传送、立即住院或入狱。玩家只选效果，目标条件由系统从条件池随机抽取，玩家不挑人；条件池包含现金/存款/地产最多或最少、男女、载具、监狱、医院、神仙、是否站在有主地产旁等。

方向选择和所有“选路面/格子”的操作都回到地图：停在交叉点时，合法方向高亮并显示箭头，点哪条路就走哪条；地雷、定时炸弹、炸药、香蕉皮、果冻墙、陷阱和路障点卡后进入地图点选模式，地图高亮所有可放路面，侧栏只显示提示和取消。这样按钮不承担空间选择，玩家看到的是棋盘本身。

商店、神秘人和研究所的卡面按侧栏宽度自动排列，卡少时散开，卡多时换行，不横向滚动；手牌少时按宽度散开，多到挤不下才叠成手牌并轻微扇形。右侧栏可拖宽，商店网格和棋盘跟着重排。股票按钮常驻；银行只能经过或停在银行格，没有银行按钮；没有重开按钮；日志常显可滚动，不显示 phase、seed 之类的调试信息。

## 体验节奏

所有时间都以“玩家能看清”为准，不以动画快为准。

| 事件 | 时长 | 规则 |
|---|---:|---|
| 逐格移动 | 0.3 秒/格 | 从原 0.5 秒缩短；每格停稳后再走下一格，不滑行 |
| 方向指针转向 | 0.15 秒 | 指针先转，角色再移动 |
| AI 相邻动作 | 0.35 秒 | 买地、选卡、点商店、掷骰之间的默认间隔 |
| AI 需要读信息的动作 | 0.5 秒 | 大建筑六选一、商店购买、银行分配 |
| 金额/卡牌/状态飘字 | 2.4 秒 | 原 1.2 秒的两倍；前 0.15 秒淡入，中段停留，最后 0.65 秒淡出 |
| 新闻/事件横幅 | 2.4 秒 | 与飘字同节奏，可点击提前关闭 |
| 骰子滚动 | 0.6 秒 | 结果先定，动画只表现结果 |
| 建造/收租高亮 | 0.4 秒 | 地块边框闪一次，不反复闪 |

飘字不叠加成一团：同一角色连续出现多条时，向上错开 20px；超过 3 条时旧的上移并淡出。

## 对话气泡与语音

角色说话时，地图上的角色 token 上方弹出漫画式气泡，气泡里写这句台词，说完自动关闭。气泡是地图的一部分，不是居中确认框，也不进侧栏日志。

- 气泡跟随角色 token，默认在 token 上方；上方超出屏幕时改到下方。
- 气泡最多显示两行，宽度随台词长度变化，尾尖指向角色。
- 气泡背景深色、文字亮色，和侧栏正文同一字号；不使用高饱和底色。
- 台词从该角色、该事件的台词池随机抽一句；同一个事件不在同一回合重复同一句。
- 气泡出现时游戏等待这句话结束，再继续下一个动作；多个事件连续触发时排队，不叠在一起。
- 气泡持续时间等于语音播放时间加 0.3 秒；没有语音素材时停留 1.8 秒；静音时停留 1.2 秒，不阻塞超过 1.2 秒。
- 点击气泡或按空格可以提前关闭，游戏立即继续。
- 语音和气泡只念台词本身，不念角色名、冒号或“某某说”；角色身份由头像和玩家栏承担。
- 20 名角色映射到 8 个中文声线和各自的音高/语速参数；本地 Edge TTS 生成 720 条 mp3，男/女、年轻/成熟角色各有差异。
- 浏览器回退只在有中文语音时使用；没有中文语音就只显示气泡文字，不逐字读中文。
- 语音、气泡和日志使用同一句台词；日志保留文字，气泡关闭后不留下居中弹窗。

## AI 节奏

AI 的每一步都要让人类看清，不瞬间连做十件事。

- 每个动作之间默认 0.35 秒；需要读信息的动作 0.5 秒。
- 移动按 0.3 秒/格；移动结束后再进入落点结算。
- 说话时暂停动作，等气泡和语音结束；说话结束到下一个动作再加 0.3 秒。
- 同一次行动内连续使用多张卡时，每张卡之间 0.35 秒。
- 人类玩家不受 AI 延迟影响；人类点完按钮立即结算。

## 动效清单

- 移动：token 在格子之间平移，0.3 秒一格，缓出。
- 转向：方向指针旋转 0.15 秒，角色不跟着转圈。
- 金额：大号正负数字从 token 上方浮起，2.4 秒淡出；收入绿色，支出红色。
- 卡片/状态：卡名或状态名从 token 上方浮起，和金额同一套节奏。
- 建造：地块边框亮一次，建筑 SVG 直接替换，不做逐帧施工。
- 传送/弹回：0.3 秒淡出淡入，落点直接出现，不做长路径动画。
- 爆炸/熔岩：0.5 秒高亮扩散，随后显示伤害飘字；不震动整个页面。
- 新闻：侧栏顶部横幅停留 2.4 秒，可点击关闭。
- 地图机关：桥开合用 0.4 秒断口变化；潮汐和熔岩用底色变化，不逐格动画。

所有动效用 CSS 过渡和短计时器；不用逐帧动画、不做 3D、不引入动画库。`prefers-reduced-motion` 打开时，移动和淡入淡出改为直接切换，仍保留文字和气泡。

## 产品决定

棋盘采用网格和三层模型，是因为棋盘的信息主体是路面、路边地产和路面上的东西，不是抽象拓扑。路面 1×1、小地产 1×1、大地产是地图定义的整块矩形、路面东西每格一个，三层各自独立；相邻只看正交共边，大地产不是两格路，也不拆成小地产。地图不先画拓扑，直接用网格填路面和地产；死路原路反弹，传送门只是可选路面类型。

初始位置和朝向随机，起始格不触发，避免开局就被收租或买地。现金和存款分离，购买只用现金，租金进存款，银行和取款才有意义。默认开局所有地产都是无主空地；地图可以预置无主联排房屋、无主大建筑或中立地标。买下普通小地产只得到空地面，下一次停到旁边才建第一层房子；买下普通大地产只得到大空地，第二次投资才选六种建筑，公园只能改建。无主已建地产买下后保留原等级和建筑类型，买下前不产生租金。街区的租金加成只数同一所有者的已建小房屋，空地面和大地产不算；大地产只负责把街区物理连通。商店九张买三张、神秘人六张买两张，买过即消失；乐透号码一到三十、全场去重、一次访问只能买一注、周期开奖、奖池累计；股票随时买卖，不依赖股票格。

魔法屋做成固定六项而不是随机弹一项，是因为停靠已经付出一次移动机会，玩家需要看到完整菜单再做取舍；效果覆盖得卡、存钱、破坏、请神、传送和监禁/住院，目标条件由系统随机抽取，玩家不挑人。右侧栏 390px、玩家信息一行式、日志占中间、底部情境区，是为了让地图保持最大面积；方向和选格回到地图，是因为按钮无法表达“周围全是路”时的空间关系。商店只显示卡面和价格，是因为卡名和效果属于 tooltip 信息，不该挤占卡面。金额飘字放在角色头顶，是因为玩家的注意力在地图上，不在右侧状态栏。

## SVG 视觉语法

五类素材先定语法，再各自细画，避免所有图标长成同一种线稿：

- **角色头像**：圆形胸像，队伍色外环，肤色、发型、配饰和角色首字区分；只出现在玩家栏，不进入地图格。
- **卡片**：竖版卡框，深色底、金色角标、中央象形图；卡面本身有边框，不和路面图标混用。
- **地产与建筑**：底部落地的建筑剪影，小房屋 1–5 级用层高和窗户区分；六种大建筑各有轮廓，公园是树与长椅；重点表现“这是一栋建筑”，不是徽章。
- **路面**：俯视单色线稿，细线、无填充、无外框，像地图上的功能符号。
- **路面上的东西**：暖色圆徽章底，粗描边，内部再画狗、雷、炸弹、神仙等；和路面线稿明显分层。

这套语法先于具体图形存在；新增卡、建筑或路面类型时，先判断属于哪一类，再按该类规则画。

## 被否掉的分支

使用方形图块、文字、表格和短过渡，保持低端设备可打开。不做居中弹窗，所有选择进右侧底部情境区。不先画拓扑再塞节点，直接用网格填路面、地产和放置物。不把大地产画成两格路或拆成小格，画成路边地图定义的整块矩形。不让商店和神秘人经过触发，必须停下。不保留重开按钮和银行按钮，银行只能通过银行格。

## 体验层现状与顺序

已经完成：角色队伍色与差异头像、五类 SVG 语法、52 张卡面、36 个建筑状态、地图 token 与方向指针、右侧栏与底部情境区、金额/卡牌/状态飘字、本地 Edge TTS 素材和浏览器中文语音回退。W3 已接入对话气泡与语音队列、统一体验时长表、AI 350/500ms 停顿、移动 0.3 秒、飘字 2.4 秒和 `prefers-reduced-motion`。

体验层仍欠：地图机关状态显示、动效收敛的剩余检查；新闻/事件横幅已接。

音频优先级：角色台词和地图事件语音在前，骰子、建造、收租和爆炸音效在后；BGM 最后。没有音频素材时只显示气泡文字，不阻塞流程。所有素材本地生成，运行时不请求外部资源。

体验层的验收标准是关掉素材仍能完整游玩，打开素材有角色辨识度和反馈，页面不产生外部网络请求，移动端在 backlog 验证。
