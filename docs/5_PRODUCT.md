# 产品

## 形态

它是一张打开的桌面：左边是网格棋盘，右边是落地侧栏。没有登录、没有后端、没有联网素材；所有视觉由方形图块、图标占位、颜色和少量文字组成。打开页面就能开一局，棋盘和侧栏是同一个界面的两半，不靠弹窗切换。

## 信息架构

右侧栏是唯一的信息与操作面板，宽度默认约 390px，左边框可以拖动调整。顶部固定显示天数、物价和股票按钮；下面是玩家状态，每名角色用一行式自动换行显示头像占位、名字、队伍、现金、存款、位置、朝向和三个槽；中间是日志，占满剩余高度并自动滚到底；底部是情境区，平时放骰子和手牌，需要选择时整块切换成买地、方向、大建筑、商店、乐透、银行、股票、魔法屋、神秘人或卡片目标面板。所有选择都在这个底部区域完成，不另开居中大弹窗。

棋盘是 25×17 网格，路面 1×1，地产 1×1 或 2×2，大地产在地图上是一整张 2×2 图块。地图里不写文字，路面、地产和大建筑用图标占位，名字和说明放在 tooltip。路面上的东西最多一个，和路面类型同时存在时两个图标叠放。人物是带方向指针的圆，当前角色高亮，指针始终指向前方。

## 视觉语言

整体是深色底、低饱和面板和金色强调。路面用单字图标占位，例如银行是“银”、商店是“店”、新闻是“新”、卡片是“卡”、乐透是“彩”、魔法屋是“魔”、税是“税”、事件是“事”；空白路面不画图标，只留底色和边框，让放置物出现时能占满整格。地产用“地”，大地产用“大”，建好后用建筑首字；有主地产用归属色边框和淡底色。地产本身没有名字或编号，界面上只有“小地产/大空地”；等级、租金和建筑效果不直接写在地图上，放在 tooltip 和后续美术里。

卡片和商店卡都是方形卡面占位：卡面里放一个字或图形，商店在卡面下只显示价格，不写卡名和效果。大地产不画内部四格，人物不画身体，只画带方向指针的圆。金额变化用大号正负数字浮在角色头顶并淡出，颜色区分收入和支出。

## 交互

回合按弃牌、用卡与银行股票、掷骰、移动、结算、换人的顺序推进，掷骰后不能继续操作。落点结算顺序固定为脚下东西、路面类型、相邻地产、方向。经过银行、乐透、送卡格和地面道具会触发；经过商店、神秘人、魔法屋和新闻不会，必须停下才触发；新闻停下后直接结算并继续处理相邻地产，不额外要求点击。多块相邻无主地逐块询问，买或放弃后继续下一块；大地产六选一；公园只能由改建卡产生。

方向选择和所有“选路面/格子”的操作都回到地图：停在交叉点时，合法方向高亮并显示箭头，点哪条路就走哪条；地雷、定时炸弹、炸药、香蕉皮、果冻墙、陷阱和路障点卡后进入地图点选模式，地图高亮所有可放路面，侧栏只显示提示和取消。这样按钮不承担空间选择，玩家看到的是棋盘本身。

商店、神秘人和研究所的卡面按侧栏宽度自动排列，卡少时散开，卡多时换行，不横向滚动；手牌少时按宽度散开，多到挤不下才叠成手牌并轻微扇形。右侧栏可拖宽，商店网格和棋盘跟着重排。股票按钮常驻；银行只能经过或停在银行格，没有银行按钮；没有重开按钮；日志常显可滚动，不显示 phase、seed 之类的调试信息。

## 产品决定

棋盘采用网格和三层模型，是因为原版的信息主体是路面、路边地产和路面上的东西，不是抽象拓扑。路面 1×1、地产 1×1 或 2×2、路面东西每格一个，三层各自独立；相邻只看正交共边，大地产是一整块 2×2 而不是两格路。地图不先画拓扑，直接用网格填路面和地产；死路原路反弹，传送门只是可选路面类型。

初始位置和朝向随机，起始格不触发，避免开局就被收租或买地。现金和存款分离，购买只用现金，租金进存款，银行和取款才有意义。开局所有地产都是无主空地，买下小地产只得到空地面，下一次停到旁边才建第一层房子；买下大地产只得到大空地，第二次投资才选六种建筑，公园只能改建。街区的租金加成只数同一所有者的已建小房屋，空地面和大地产不算；大地产只负责把街区物理连通。商店九张买三张、神秘人六张买两张，买过即消失；乐透号码一到三十、全场去重、一次访问只能买一注、周期开奖、奖池累计；股票随时买卖，不依赖股票格。

右侧栏 390px、玩家信息一行式、日志占中间、底部情境区，是为了让地图保持最大面积；方向和选格回到地图，是因为按钮无法表达“周围全是路”时的空间关系。商店只显示卡面和价格，是因为卡名和效果属于 tooltip 信息，不该挤占卡面。金额飘字放在角色头顶，是因为玩家的注意力在地图上，不在右侧状态栏。

## 被否掉的分支

不做 3D、等距和精灵动画，方形图块足够且成本最低。不做实时联机、账号、匹配、手柄和任何互联网功能，只做本地热座。不做逐帧动画和复杂 K 线，用文字、表格和短过渡代替。不做居中弹窗，所有选择进右侧底部情境区。不先画拓扑再塞节点，直接用网格填路面、地产和放置物。不把大地产画成两格路或四个小格，画成路边一整块 2×2。不让商店和神秘人经过触发，必须停下。不保留重开按钮和银行按钮，银行只能通过银行格。

## 体验层

体验层按低成本、高辨识度排序：先做角色主色、短称号和头像位，再做场景台词与字幕，然后接浏览器 TTS，再做金币飞字、骰子滚动、逐格高亮和资产变化，再做新闻横幅、领主资产条、物价上涨和破产提示，最后做地图主题配色、选人开局界面、快捷键和跳过动画。动画只用 CSS 和短过渡，不做逐帧。

体验层的验收标准是关掉素材仍能完整游玩，打开素材有角色辨识度和反馈，页面不产生外部网络请求，移动端能操作。明确不做 3D、骨骼动画、逐帧特效、复杂粒子、K 线和剧情演出。
