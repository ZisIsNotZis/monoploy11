# 产品

## 形态

一个静态网页，打开即是一张“桌面”：中间棋盘，四周是人和信息。没有登录、没有后端、没有素材加载。所有视觉由文字、颜色、边框、简单 SVG 线构成。

## 信息架构

- 顶部状态条：天数、物价指数、当前回合、当前模式、种子。
- 中央棋盘：节点（格子）+ 边（道路）+ 传送/车站连线；两层地图可切换层。
- 左侧：参赛者列表（头像位用色块+名字），现金/存款/资产/卡片数/神仙/状态/队伍；每人固定显示三个槽位（神仙/状态/第三槽）。
- 右侧：行动面板（当前可做的操作）+ 日志（可折叠、可回溯）。手牌上限 8 张（领主天赋可放宽），超限只在回合开始弃牌。
- 底部：手牌区（卡名、类别、距离、可用状态）、骰子与结束回合。
- 弹层：商店、研究所、魔法屋、股票、乐透、银行、新闻、结盟提议、结算。

## 棋盘语言

- 每格一个短标签：空、地、大、银、股、彩、店、魔、新、神、医、监、卡、传、站、机、税、狗、乞。
- 颜色只区分所有权与类型：己方/队友/对手/中立/功能格。
- 等级用数字角标（1–5），建筑类型用第二个短标签（商/饭/地/书/能/研/公）。
- 道路用细线；单向与机关转向用箭头；传送与上下层用虚线 + 同色编号。
- 角色用圆形色块 + 名字首字，叠在格子上；多名角色同格时横向排开。

## 交互

- 掷骰 → 逐格高亮移动 → 落点结算 → 行动面板给出合法操作。
- 使用卡片：点卡 → 棋盘高亮合法目标 → 点目标 → 确认。非法目标不亮。
- 商店/研究所/魔法屋：列表 + 价格 + 效果一句话 + 确认；不展示原版卡图。
- 所有随机结果先写日志再改变 UI，避免“看不见的结算”。
- AI 回合默认 0.4 秒一步，可调速/暂停；关键决策在日志里用一句话说明理由。
- 键盘：空格掷骰/结束，数字键选卡，Esc 取消。

## AI 的常识（最低要求）

规则型启发式，不接 LLM：

- 会算“这块地多久能回本”，现金低于两轮租金时留钱。
- 会优先买能凑成同街道的地、会升级高流量地块。
- 会躲高租金、会用路障/乌龟/转向把对手送进去。
- 会在大额伤害前用无懈/转移；会把卡留给领主。
- 结盟看资产差与领主威胁，不无条件接受；被背叛后降低信任。

## 已做的产品决定

- 用图（节点+边）描述地图，而不是像素坐标：这样拓扑等价优先，排版可以自动/手调。
- 用数据表 + 效果解释器描述卡/角色/神仙/建筑：新增内容不改引擎。
- 零依赖 ES Modules、无构建步骤：浏览器直接加载 `src/*.js`，`python3 -m http.server` 即玩；测试用 `node --test`。少一层工具链就少一层成本。
- 小游戏不做，落格直接按期望值折算金钱（数值待定，标为复刻偏差）。

## 被否掉的分支

- 3D / 等距 / 精灵图：成本高、与“零素材”冲突。
- 音乐、语音、音效：用户明确不要。
- 后端、账号、实时联机：第一版不需要，联机留到规则稳定后。
- 直接复刻原版 UI 布局：原版为 3D 镜头服务，文字版需要另一套信息密度。
- 用 canvas 画一切：文字与 DOM/SVG 更易读、可选中、可测试。

## 体验目标

打开 30 秒内能开一局；一屏能看懂“我是谁、我有多少钱、轮到谁、我能做什么”；一局结束后能回看每一步为什么发生。

## 候选“永久不做”（待用户确认）

| 项 | 处理 | 理由 |
|---|---|---|
| 小游戏 | 永久不做，落格随机给钱 | 实现复杂度高、与核心乐趣无关 |
| 原版美术/音乐/语音/3D/剧情/成就/装扮 | 永久不做 | 与“零素材、纯文字”目标冲突 |
| 实时联机/账号/匹配 | 永久不做 | 单机热座已覆盖核心；联机是另一个产品 |
| 隐藏概率与系数的逐帧反推 | 永久不做，用可调近似值 | 成本高、收益低、无法保证正确 |
| 9 张资料不足地图的逐格还原 | 永久用“同构简化图” | 公开资料不足；拓扑等价优先 |
| 地图机关的逐帧动画 | 永久不做，文字日志表达 | 表现层降级 |
| 股票 K 线/复杂金融 UI | 永久不做，表格代替 | 表现层降级 |
