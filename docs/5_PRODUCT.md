# 产品

## 形态

一个静态网页，打开就是一张桌面：左侧是网格棋盘，右侧是落地侧栏。没有登录、没有后端、没有素材加载；所有视觉由方形图块、图标占位、颜色与少量文字构成。

## 信息架构

- **右侧栏（约 390px，落地）**
  - 顶部：天数、物价、股票按钮。
  - 玩家状态：每名角色一行式自动换行，含头像占位、名字、队伍、现金/存款、位置/朝向、三槽。
  - 中间：日志，占满剩余高度，可滚动。
  - 底部：情境区。平时是骰子行 + 卡片行；需要选择时整块切换为选择面板（买地、方向、大建筑、商店、乐透、银行、股票、魔法屋、新闻、神秘人、卡牌目标）。
- **棋盘**
  - 25×17 网格；路面 1×1，地产 1×1/2×2；同一单位方格。
  - 地图里不写文字；路面/地产/建筑用图标占位，说明放 tooltip。
  - 路面上的东西最多 1 个；和路面类型同时存在时两个图标缩小错开。
  - 人物是带方向指针的圆；当前角色高亮。

## 视觉语言

- 深色底；路面用 `·`、`银`、`店`、`卡`、`彩`、`魔`、`税`、`事`、`新` 等图标占位。
- 地产用 `地`（小）、`大`（大空地）或建筑首字；有主后加归属色边框/底色；等级只在 tooltip 和后续美术里表达。
- 大地产是一整张 2×2 图块，不画内部四格。
- 不显示 phase、seed、resolve 等调试信息。

## 交互

- 回合：弃牌 → 用卡/股票/银行 → 掷骰 → 移动 → 结算 → 换人。
- 掷骰前可用卡、股票、银行；掷骰后不能继续。
- 落点结算顺序：脚下东西 → 路面类型 → 相邻地产 → 方向。
- 经过生效：银行、乐透、送卡格、地面道具；商店/神秘人/魔法屋/新闻要停下。
- 所有需要选择的动作都在右侧栏底部变成选择面板，不弹中间大窗。
- 多块相邻无主地逐块询问；大地产 6 选 1；公园只能改建卡产生。
- 卡片少时按宽度散开，多到挤不下才叠成手牌扇形，不横向滚动。
- 股票按钮常驻；银行、重开按钮不做。
- 骰子只显示可用数量（1/2/3），不写“最多几骰”的说明。
- 金钱变化在角色状态旁飘出大号 `+/-` 数字。

## 已做的产品决定

- 网格棋盘 + 三层模型：路面、地产、路面上的东西互不冲突。
- 地图不先画拓扑；路面邻接即连通，地产靠边接触即触发。
- 大地产是 2×2 一整块，占用四格，不是两格路。
- 初始位置/朝向随机；初始格不触发。
- 死路反弹；传送门只是可选路面类型。
- 现金/存款分离；租金进存款；购买只用现金。
- 大地产先买空地，第二次投资选 6 种建筑；公园只能改建。
- 商店 9 张买 3、神秘人 6 张买 2；买过即消失。
- 乐透号码 1–30、全场去重、周期开奖、奖池累计。
- 股票随时买卖，不依赖股票格。
- 右侧栏 390px；玩家信息压成一行式；日志占中间；底部是情境区。
- 卡片/骰子分行错开；卡片自适应散开/叠放。
- 2D 标识、头像、台词、TTS、BGM 作为 M3 体验层；3D/剧情/成就/装扮永久不做。

## 被否掉的分支

- 3D / 等距 / 精灵动画：成本高；方形图块足够。
- 实时联机、账号、匹配、手柄、任何互联网功能：只做本地热座。
- 逐帧动画、复杂 K 线：文字/表格/短过渡代替。
- 弹窗居中：改为右侧栏底部情境区。
- 地图像素坐标先画拓扑：改为网格填路面/地产/放置物。
- 大地产画成两格路或四个小格：改为路边一整块 2×2。
- 商店/神秘人经过触发：改为必须停下。
- 重开/银行按钮：删除；银行只能经过银行格。

## 体验层设计（M3）

按“低成本 / 高辨识度”排序：

1. 角色辨识：主色、短称号、头像位（自绘 SVG 或本地抠图）。
2. 台词与声音：场景台词；字幕常显；TTS 按角色声线。
3. 即时反馈：骰子滚动、逐格高亮、金币飞字、资产变化。
4. 戏剧性播报：新闻横幅、领主资产条、物价上涨、破产提示。
5. 节奏：可跳过动画、可加速、回合摘要。
6. 地图主题：不同地图配色与格图标；机关简短提示。
7. 上手：卡片一句话说明、可用操作高亮、首次 3 步提示。
8. 重玩：角色/地图/规则组合、固定种子。

明确不做：3D、骨骼动画、逐帧特效、复杂粒子、K 线、剧情演出。
