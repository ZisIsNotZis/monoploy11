# Monopoly 11 规则书

## 1. 游戏是什么

Monopoly 11 是一款回合制棋盘游戏。参赛者轮流掷骰、沿道路移动、购买地产、建造建筑、收取租金、使用卡片、经营资金，最后按队伍总资产或破产结果决定胜负。

一局至少两名参赛者。每名参赛者由人类或 AI 控制，选择一个角色，属于一个队伍。所有参赛者在同一台设备上轮流操作，所有操作在本地完成。

角色数据决定这个角色有哪些技能；技能档位也由角色数据决定。技能只改明确写到的规则，没有写到的规则保持不变。

## 2. 一局开始前

### 2.1 生成配置

本地设置界面生成一份配置，规则层只读这份配置。配置决定：

- 参赛者数量、每名参赛者的控制者、队伍。
- 每名参赛者选择的角色和技能档位。
- 地图。
- 初始现金、初始存款、初始手牌数量和内容。
- 手牌上限、天数上限、物价初始值、物价上涨步长和间隔。
- 银行利率和结息周期。
- 载具的骰子数量和移动范围。
- 乐透号码范围、票价、开奖周期、初始奖池。
- 地产购买价、建造费、升级费、基础租金、最高等级、街区倍率。
- 医院和监狱的停留回合数。
- 商店、神秘人、研究所的展示数量、购买上限和价格。
- 随机种子。

这些值不写死在规则里。设置界面可以给默认值，但默认值不是规则。

颜色由系统按队伍分配，同一队伍同一色相，队员靠明度区分。角色就是参赛者的身份。

### 2.2 地图

地图是一份数据，决定棋盘的大小、形状、路面、地产和初始机关。不同地图可以有不同宽高和不同路线，不要求固定尺寸。

棋盘分三层：

- **路面层**：可走格，每格有路面类型和坐标；角色沿正交相邻路面移动。
- **地产层**：路边不可走格；小地产占一格，大地产占一整块矩形；地产至少有一条边和路面共边，对角接触不算相邻。
- **放置物层**：路面上的东西，每格最多一个；角色不占用放置物层，一格可以站多名角色。

街区按物理连接定义：连在一起的小地产和大地产属于同一街区，不管归谁。街区长度上限、每街区大地产数量上限由地图数据给出。大地产提供街区连通性，但不计入小房屋的街区租金加成。

死路只有一条出边时，角色原路反弹，继续剩余步数。传送门只是可选路面类型，不承担死路出口。

### 2.3 初始状态

每名参赛者按配置获得初始现金、初始存款、初始手牌。

所有参赛者随机落在不同路面格，随机朝向一个合法方向。起始格不触发任何结算。

所有地产开局为空地：小地产是空地面，大地产是大空地。所有参赛者都没有初始地产。

### 2.4 先手与座次

先手由配置决定，之后按座次顺序循环。

## 3. 一回合的完整流程

每名参赛者的回合按以下顺序执行：

1. **回合开始**：绑定槽和人物槽的剩余天数减一；物理槽的住院/入狱回合数减一。处理“回合开始”技能。
2. **弃牌**：手牌超过手牌上限时，弃到上限。
3. **行动**：使用手牌、打开银行面板、买卖股票。银行只在经过或停在银行格时打开。
4. **掷骰**：按载具的骰子数量掷骰，取点数之和。
5. **移动**：沿路面逐格前进，每格结算该格的经过事件。
6. **落点结算**：停在一个路面格后，按以下顺序结算：
   1. **脚下的东西**：神仙、野狗、乞丐、神秘人、地雷、炸药、定时炸弹、香蕉皮、果冻墙、陷阱、路障。
   2. **路面类型**：按第 5 节的路面表处理。
   3. **相邻地产**：按第 6 节的相邻地产结算处理。
   4. **事后神**：如果当前神仙是福神、天使、土地公或凶神，按第 14 节结算它的落点后效果。
   5. **方向**：如果停在交叉点，按第 4 节选择方向。
7. **结束回合**：处理“回合结束”技能，换下一名参赛者。

掷骰之后不能使用卡片、买卖股票或存取款。只有落点结算全部结束后，才换下一名参赛者。

## 4. 移动

### 4.1 掷骰

每名参赛者按当前载具的骰子数量掷骰。步行、机车、汽车各自掷不同数量的骰子；具体数量由载具数据给出。移动步数是所有骰子的点数之和。

### 4.2 逐格移动

角色沿路面正交邻接逐格前进。每走到一格，结算该格的经过事件，再继续下一格。

经过交叉点但不停下时，随机选择一个非来路方向，继续剩余步数。正好停在交叉点时，不立即选方向；等落点全部结算完，再选方向。

死路只有一条出边时，角色原路反弹，继续剩余步数。

### 4.3 方向

停在交叉点时，合法方向是除当前朝向外所有可走方向；如果当前朝向不是合法出边，则所有出边都可选。选中方向后，角色朝该方向，回合结束。

每次移动结束且没有待选方向时，角色朝向固定为前方非来路方向。

## 5. 落点

### 5.1 脚下的东西

先处理落点格上的放置物：神仙、野狗、乞丐、地雷、炸药、定时炸弹、香蕉皮、果冻墙、陷阱、路障。每格最多一个放置物；角色不阻挡角色。

| 东西 | 效果 |
|---|---|
| 神仙 | 按第 14 节附身该神仙 |
| 野狗 | 住院配置回合数；汽车和明确免疫野狗的技能可以躲开 |
| 乞丐 | 支付配置金额 × 物价指数；支付后乞丐消失 |
| 地雷 | 支付配置金额 × 物价指数，住院配置回合数 |
| 炸药 | 支付配置金额 × 物价指数，住院配置回合数 |
| 定时炸弹 | 附身到经过者，按配置步数倒计时，爆炸后支付配置金额 × 物价指数 |
| 香蕉皮 | 支付配置金额 × 物价指数 |
| 果冻墙 | 弹回配置步数，不损失钱 |
| 陷阱 | 停留配置回合数 |
| 路障 | 停止移动，剩余步数取消 |

### 5.2 路面类型

脚下东西处理完后，按路面类型处理：

| 类型 | 触发 | 效果 |
|---|---|---|
| 空路 | 无 | 无 |
| 银行 | 经过或停下 | 进入银行流程，见第 8 节 |
| 乐透 | 经过或停下 | 进入乐透流程，见第 10 节 |
| 卡片 | 经过或停下 | 获得一张基础卡 |
| 商店 | 停下 | 按配置展示基础卡并购买，见第 5.3 节 |
| 神秘人 | 停下 | 按配置展示卡片并购买，见第 5.3 节 |
| 研究所 | 停下 | 按配置展示进阶卡并研发，见第 5.3 节 |
| 魔法屋 | 停下 | 进入魔法屋选项，见第 11 节 |
| 新闻 | 停下 | 立即结算一条新闻，见第 13 节 |
| 税 | 停下 | 支付配置规定的税款，按第 7 节付款 |
| 事件 | 停下 | 立即结算一条事件，见第 13 节 |
| 医院 | 进入 | 住院配置回合数，位置移到医院入口；出院回到入口 |
| 监狱 | 进入 | 入狱配置回合数，位置移到监狱入口；出狱回到入口 |
| 传送门 | 停下 | 移动到配对的传送门，不触发落点 |
| 起点 | 经过 | 获得配置规定的工资；起始格不触发 |

商店、神秘人、研究所、魔法屋、新闻、税、事件的面板关闭后，继续处理相邻地产。

### 5.3 商店、神秘人与研究所

商店、神秘人和研究所都在停下时打开面板，购买后立即结算，买过的卡从列表消失。

- 展示数量、购买上限、价格和卡池由配置给出。
- 商店展示基础卡；研究所展示进阶卡；神秘人按配置展示。
- 买满购买上限时自动关闭面板；关闭后继续处理相邻地产。

## 6. 地产

### 6.1 相邻地产结算

停到一个路面后，所有和该路面正交共边的地产按地块 id 顺序逐块结算。每块按以下顺序：

1. 对手地产：支付租金。
2. 队友地产：不付租金。
3. 自己的空地：买下后为空地，第一次停到相邻路面时建造。
4. 自己的已建地产：升级。
5. 无主地产：询问买不买；买下或放弃后继续下一块。

一个路面同时贴多块地产时，必须逐块处理，处理完才进入下一步。

### 6.2 买地

无主地产被询问时，支付配置的购买价，地产归购买者，状态变为空地。购买价乘以当前物价指数。购买只能用现金。

### 6.3 建造

停到自己的空地相邻路面时建造：

- 小地产：建造唯一的小房屋，等级变为 1。
- 大地产：从第 16 节的大建筑表中选择一种建筑，等级变为 1。公园不能在这里选，只能由改建卡产生。

建造费乘以当前物价指数。建造只能用现金。

### 6.4 升级

停到自己的已建地产相邻路面时升级：

- 小房屋：等级加一，最高等级由配置给出。
- 大建筑：等级加一，最高等级由配置给出。

升级费乘以当前物价指数。升级只能用现金。

空地和升级没有关系：空地只能先建造，已建地产才能升级。大空地不是“大建筑等级 0”，它没有建筑类型。

### 6.5 租金

小地产租金 = 基础租金 × 物价指数 × 街区倍率。

基础租金由地产等级和配置给出；街区倍率按同一所有者、同一街区内已建成的小房屋数量计算，空地面和大地产不计入数量。停业状态租金为零；涨价状态租金翻倍。

大地产租金按大建筑类型和等级单独计算，见第 16 节。

地产不能主动出售。破产时地产归属清空，建筑和等级保留；其他参赛者再买下时保留原层数和建筑类型。

## 7. 资金、付款与破产

现金和存款是两种资金。所有金额先乘物价指数（配置明确写“不乘”的除外）。

**强制付款**（租金、税、罚款、事件损失、爆炸损失）按以下顺序扣：

1. 先扣现金。
2. 现金不足时，扣存款。
3. 现金和存款都扣完仍不足以支付时，现金和存款都归零，宣布破产。

**主动购买**（买地、建造、升级、买卡、买股票、买乐透）只能用现金；现金不足时不能购买，不能自动从存款扣。

租金进入收款人的存款，不进入现金。工资、事件奖励和卡片奖励进入现金。

资产 = 现金 + 存款 + 地产估值 + 股票市值。地产估值 = 购买价 + 已付建造费。

破产时，破产者退出游戏，地产归属清空但建筑保留，手牌移出游戏。破产者的债权人先拿走剩余现金和存款，再处理地产归属。

## 8. 银行

银行只在经过或停在银行格时打开。银行面板可以反复存款、取款，单次操作不结束面板，关闭后继续移动。

存款按配置的周期和利率结息，利息进入存款。存款不直接参与购买，只在强制付款时作为第二资金来源。

## 9. 股票

股票是独立系统，不需要股票格。每支股票有名称、当前价格和持有数量。

- 股票数量、名称和初始价格由配置给出。
- 持有数量为非负整数，不能做空。
- 买入用现金，卖出回现金。
- 每天每支股票按配置的漂移和波动变动，单日涨跌幅不超过配置上限。
- 股票计入总资产，但不计入地产估值。

## 10. 乐透

乐透是独立系统，只在乐透格触发。一次访问只能买一注。

- 号码范围、票价、开奖周期、初始奖池和奖池增长由配置给出。
- 同一期全场同一个号码只能卖一次；已售号码不能再次购买。
- 开奖时随机抽一个号码。无人中奖时奖池累计，票和已售号码保留；有人中奖后清空票和已售号码，奖池回到初始值。
- 中奖金额进入现金。

## 11. 魔法屋

停在魔法屋后，从魔法屋选项表中选择一项。一次停靠只能选一次，不花钱。没有合法目标的选项不可选；选择目标时取消会回到选项表，不消耗这次停靠。

魔法屋选项表：

1. **获得三张卡片**：随机获得三张基础卡。手牌可以暂时超过上限，下一次自己回合开始时再弃牌。
2. **天降横财**：现金增加配置的金额。
3. **免费加盖**：选择己方一处已建成、未停业的小地产，等级加一，最高不超过配置的最高等级。
4. **强制降级**：选择对手一处已建成的小地产，等级减一，最低为零；不删除地产、不改归属。
5. **神仙附身**：随机一位神仙附身配置的天数，顶替当前神仙；不立刻触发该神仙的落点效果。
6. **牢狱之灾**：选择一名不在监狱、不在医院的对手，入狱配置的回合数并移到监狱入口。

## 12. 卡片

卡组由基础卡和进阶卡组成；具体卡片、效果、目标和限制见卡片附录。

### 12.1 手牌

手牌上限由配置给出。超过上限只在本人回合开始时弃牌。手牌没有其他上限。

### 12.2 获取

基础卡从商店、神秘人、卡片格、事件和角色技能获得；进阶卡由五张同名基础卡合成。具体获取渠道见卡片附录。

### 12.3 五合一

五张同名基础卡自动合成一张对应的进阶卡。配方见卡片附录。合成不消耗行动。

### 12.4 目标

卡片目标分自身、角色、地块、街区和全场。使用前必须有合法目标；没有合法目标时不能使用。

- 角色目标：点角色，范围由卡片数据给出。
- 地块目标：点地产，范围由卡片数据给出。
- 街区目标：点街区内任意地产，按该地产所在街区结算。
- 路面目标：点路面，范围由卡片数据给出。
- 全场目标：不需要目标。

### 12.5 响应卡

响应卡在对应时机自动询问，手牌中显示为不可主动使用。

- **免费卡**：单次强制付款达到配置阈值时询问；消耗后取消本次付款。
- **无懈卡**：对手对你使用指向性卡片时询问；消耗后取消该卡。
- **转移卡**：你入狱、入院或单次损失达到配置阈值时询问；消耗后选择另一名合法角色承担。
- **同命卡**：对手对你使用梦游、冬眠或谋划时询问；消耗后把同一效果反弹给使用者。

## 13. 新闻与事件

新闻和事件从同一张事件表抽取，按表结算一次。新闻停在新闻格触发；事件停在事件格触发。

| 事件 | 效果 |
|---|---|
| 物价上涨 | 物价指数增加配置步长 |
| 股市大涨 | 所有股票价格按配置比例上涨 |
| 股市大跌 | 所有股票价格按配置比例下跌 |
| 中奖 | 现金增加配置金额 × 物价指数 |
| 罚款 | 支付配置金额 × 物价指数 |
| 住院 | 住院配置回合数 |
| 入狱 | 入狱配置回合数 |
| 获得卡片 | 获得配置数量的随机基础卡 |
| 失去卡片 | 随机失去配置数量的手牌 |
| 全体发钱 | 每名参赛者现金增加配置金额 × 物价指数 |
| 全体收钱 | 每名参赛者支付配置金额 × 物价指数 |
| 传送 | 随机传送到一个空路面格，不触发落点 |

## 14. 神仙

神仙占用绑定槽；基础附身天数由配置给出。新神仙顶替旧神仙，旧神仙直接离开，没有补偿。神仙效果分“附身时”“附身期间”和“落点后”；落点后效果只在移动结束、相邻地产结算完后触发。

| 神仙 | 附身时 | 附身期间 | 落点后 |
|---|---|---|---|
| 财神 | 向每位对手收取配置金额 | 免除租金和付费 | 无 |
| 穷神 | 向每位对手赠送配置金额 | 租金和付费翻倍 | 无 |
| 福神 | 获得参数指定数量的随机基础卡 | 停在己方地产免费加盖一层 | 己方相邻地产各免费加盖一层 |
| 衰神 | 随机失去参数指定数量的手牌 | 走到己方地产不能加盖 | 无 |
| 天使 | 无 | 走到任何地产，该地免费加盖一层 | 所有相邻地产各免费加盖一层 |
| 恶魔 | 无 | 走到任何地产，该地下降一层；空地不破坏 | 无 |
| 土地公 | 无 | 走到非己方地产，将其占为己有 | 收走所有非己方相邻地产 |
| 糊涂神 | 无 | 每次前进随机转向；使用卡片按配置概率失败，失败不退还卡片 | 无 |
| 武神 | 无 | 所有卡片使用范围增加配置步数 | 无 |
| 凶神 | 无 | 税、事件、新闻、野狗、乞丐对自身无效 | 撤销本次落点中自己刚建或刚升的房屋 |

请神和送神的具体卡片效果见卡片附录。

## 15. 角色与技能

每名参赛者选择一个角色。角色数据给出角色技能和技能档位；开局配置选择使用哪个档位。技能只改明确写到的规则，没有写到的规则保持不变。

角色表、技能文本和档位见角色附录。

## 16. 大建筑

大建筑由大地产建造，最高等级由配置给出。建造费和升级费按配置乘以物价指数。

| 建筑 | 效果 |
|---|---|
| 商业中心 | 对手停在此格时支付租金：基础租金 × 等级 × 物价指数 × 转盘数 |
| 大饭店 | 对手停在此格时支付基础租金 × 等级 × 物价指数，并被强制住店配置回合数 |
| 地产公司 | 己方应付租金降低配置比例 × 等级，最高不超过配置上限 |
| 书店 | 己方离开商店或神秘人时，按等级对应的概率获得若干张卡 |
| 能源中心 | 对手买卡价格增加配置比例 × 等级；自己停在此格获得配置金额 × 等级 × 物价指数 |
| 研究所 | 研发进阶卡；等级决定可研发卡池，最多展示配置数量 |
| 公园 | 不收费、不加成；只能由改建卡把其他大建筑改成公园 |

改建卡可以更换大建筑的设施类型；工程车卡和怪兽卡每次降一级；等级降到零后大建筑消失，恢复大空地。

## 17. 状态

每名参赛者有三个状态槽：

- **绑定槽**：神仙、定时炸弹，按天或步数倒计时。
- **人物槽**：乌龟、梦游、冬眠、冰冻、停留，按天倒计时。
- **物理槽**：监狱、医院，按回合倒计时。

同槽新状态顶替旧状态。梦游和冬眠跳过回合；乌龟每次只能走配置步数；冰冻点数视为零并原地再触发一次落点；停留跳过本回合移动。

## 18. 胜负

满足任一条件时游戏结束：

- 只剩一支队伍。
- 天数达到配置上限。

游戏结束时，队伍总资产 = 队伍所有成员现金 + 存款 + 地产估值 + 股票市值。总资产最高的队伍获胜；并列时依次比较存款、地产数量、随机种子决定的顺序。

破产者退出游戏。破产者的队伍如果全部破产，该队伍失败；否则继续比较剩余队伍。

## 19. 操作

开局界面生成本地配置：参赛者、控制者、队伍、角色、地图、所有可调参数、种子。开始后进入棋盘。

右侧栏从上到下是：

- 天数、物价和股票按钮。
- 每名参赛者一行：头像、角色、队伍、现金、存款、位置、朝向、三个状态槽。
- 日志。
- 底部情境区：平时显示骰子和手牌；需要选择时切换成买地、建造、升级、方向、商店、乐透、银行、股票、魔法屋、神秘人或卡片目标面板。

操作规则：

- 点骰子掷骰；掷骰后不能再用卡或买卖。
- 点手牌使用卡片；响应卡不能主动点。
- 点地图上的地产、路面或角色选择空间目标。
- 点右侧栏按钮确认或取消面板操作。
- 金额、卡片、状态变化以浮动文字显示在角色头顶。

## 20. AI 操作

AI 和人类使用同一套规则与同一个行动入口，不读取隐藏信息。每回合按配置的评分表决策：保命响应优先，其次购买、建造、升级、用卡、移动目标。AI 不使用 LLM，不访问网络，不读取随机种子之外的未来信息。
