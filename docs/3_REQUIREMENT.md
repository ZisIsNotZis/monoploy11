# Monopoly 11 规则书

## 1. 游戏是什么

Monopoly 11 是一款回合制棋盘游戏。参赛者轮流掷骰、沿道路移动、购买地产、建造建筑、收取租金、使用卡片、经营资金，最后按队伍总资产或破产结果决定胜负。

一局至少两名参赛者。每名参赛者由人类或 AI 控制，选择一个角色，属于一个队伍。所有参赛者在同一台设备上轮流操作，所有操作在本地完成。

角色数据决定这个角色有哪些技能；技能档位也由角色数据决定。技能只改明确写到的规则，没有写到的规则保持不变。

## 2. 一局开始前

### 2.1 生成配置

本地设置界面生成一份配置，规则层只读这份配置。配置决定：

- 参赛者数量、每名参赛者的控制者、队伍。
- 每名参赛者选择的角色和技能档位。
- 地图。
- 初始现金、初始存款、初始手牌数量和内容。
- 手牌上限、天数上限、物价初始值、物价上涨步长和间隔。
- 银行利率和结息周期。
- 载具的骰子数量和移动范围。
- 乐透号码范围、票价、开奖周期、初始奖池。
- 金钱格的现金上限。
- 地产购买价、建造费、升级费、基础租金、最高等级、街区倍率。
- 医院和监狱的停留天数。
- 商店、神秘人、研究所的展示数量、购买上限和价格。
- 随机种子。

这些值不写死在规则里。设置界面可以给默认值，但默认值不是规则。

### 2.2 地图

地图是一份数据，决定棋盘的大小、形状、路面、地产和初始机关。不同地图可以有不同宽高和不同路线，不要求固定尺寸。

棋盘分三层：

- **路面层**：可走格，每格有路面类型和坐标；角色沿正交相邻路面移动。
- **地产层**：路边不可走格；小地产占一格，大地产占一整块矩形；地产通过正交共边和路面关联，对角接触不算相邻。不贴路的地产无法被任何落点触发；这是地图设计要避免的问题，不是规则禁止的非法状态。
- **放置物层**：路面上的东西，每格最多一个；角色不占用放置物层，一格可以站多名角色。

街区按物理连接定义：连在一起的小地产和大地产属于同一街区，不管归谁。街区长度上限、每街区大地产数量上限由地图数据给出。大地产提供街区连通性，但不计入小房屋的街区租金加成。

死路只有一条出边时，角色原路反弹，继续剩余步数；地图设计应避免无意义死路。传送门只是可选路面类型，不承担死路出口。

### 2.3 初始状态

每名参赛者按配置获得初始现金、初始存款、初始手牌。

所有参赛者随机落在不同路面格，随机朝向一个合法方向。起始格不触发任何结算。

所有地产开局为空地：小地产是空地面，大地产是大空地。所有参赛者都没有初始地产。

### 2.4 先手与座次

先手由配置决定，默认从 1 号座位开始，之后按座次顺序循环。

## 3. 一局怎么进行

### 3.1 回合开始

轮到一名参赛者时，先处理回合开始：

1. 处理“回合开始”技能。
2. 如果角色处于梦游、冬眠、住院或入狱，跳过本回合的弃牌、行动、掷骰和移动，直接进入回合结束。

“一天”是**所有参赛者各完成一个回合**。天数只在最后一名参赛者的回合结束后增加，不是每名参赛者走一步就算一天。

状态持续时间按该角色自己的回合结算：在该角色回合结束时，绑定槽、人物槽和物理槽的剩余计数各减一；减到零时状态结束。

状态分三个槽：

- **绑定槽**：神仙、定时炸弹，按天或步数倒计时。
- **人物槽**：乌龟、梦游、冬眠、冰冻、停留，按天倒计时。
- **物理槽**：监狱、医院，按天倒计时。

同槽新状态顶替旧状态。乌龟每次只能走配置步数；冰冻点数视为零，并在原地再触发一次落点；停留跳过本回合移动。

### 3.2 弃牌

手牌超过手牌上限时，弃到上限。手牌上限由配置给出；角色技能可以覆盖它。弃牌只在本回合开始时发生。

### 3.3 行动

弃牌后进入行动阶段。行动阶段可以按任意顺序做以下事情：

- 使用手牌。
- 打开银行面板（只在经过或停在银行格后可用）。
- 买卖股票。

掷骰之后，行动阶段立即结束；不能再使用手牌、买卖股票或存取款。

#### 3.3.1 使用手牌

卡片分基础卡和进阶卡；具体卡片、效果、目标和限制见本节卡片表。

手牌没有其他上限。五张同名基础卡自动合成一张对应的进阶卡，合成不消耗行动。

使用卡片前必须有合法目标；没有合法目标时不能使用。目标分：

- 自身：直接使用。
- 角色：点角色，范围由卡片数据给出。
- 地块：点地产，范围由卡片数据给出。
- 街区：点街区内任意地产，按该地产所在街区结算。
- 路面：点路面，范围由卡片数据给出。
- 全场：不需要目标。

响应卡在对应时机自动询问，手牌中显示为不可主动使用：

- **免费卡**：单次强制付款达到配置阈值时询问；消耗后取消本次付款。
- **无懈卡**：对手对你使用指向性卡片时询问；消耗后取消该卡。
- **转移卡**：你入狱、入院或单次损失达到配置阈值时询问；消耗后选择另一名合法角色承担。
- **同命卡**：对手对你使用梦游、冬眠或谋划时询问；消耗后把同一效果反弹给使用者。

基础卡从商店、神秘人、卡片格、事件和角色技能获得；进阶卡由五张同名基础卡合成。五合一配方：飞弹→急速弹、涨价→辉煌、停业→窘困、送神→绿化、怪兽→灾祸、请神→神眷。商店、神秘人和研究所的展示数量和购买上限由配置给出，单卡价格按上表。

#### 3.3.2 银行

银行只在经过或停在银行格后可用；银行面板的存取规则见第 3.5.2 节的银行格。行动阶段打开银行面板不结束回合，关闭后回到行动阶段。

#### 3.3.3 股票

股票是独立系统，不需要股票格。每支股票有名称、当前价格和持有数量。

默认股票列表：

| 股票 | 初始价格 |
|---|---:|

| 地产股 | 50 |
| 科技股 | 50 |
| 能源股 | 50 |
| 媒体股 | 50 |
| 医药股 | 50 |
| 消费股 | 50 |
| 交通股 | 50 |

1. 取 −10% 到 +10% 之间的随机数 r。
2. 新价格 = round(旧价格 × (1 + r))。
3. 新价格最低为 1。

### 3.4 掷骰

行动结束后掷骰。每名参赛者按当前载具的骰子数量掷骰：步行、机车、汽车各自掷不同数量的骰子；具体数量由载具数据给出。移动步数是所有骰子的点数之和。

掷骰之后不能再执行行动阶段的操作。

### 3.5 移动

#### 3.5.1 逐格移动

角色沿路面正交邻接逐格前进。两个路面格只要有正交共边，就可以走；不需要额外道路类型。移动从当前朝向开始；朝向就是角色上一段真实移动的方向，移动中不会一边走一边把箭头拧向另一条路。当前朝向不是合法出边时，按 3.6.5 重新选方向。

每走到一格，结算该格的经过事件，再继续下一格。每进入一格消耗一步。如果中途被送进医院、监狱、传送走或被卡片移动到别处，立即停止剩余移动，不再结算后面的格。

一条路只连两个路面格时，方向自动保持；一个路面格连三个或更多路面格时，它是岔路，按 3.6.5 选择方向。方向会持续到下一个岔路、死路或强制转向；没有事件改变方向时，角色不会每一步重新选方向。

死路只有一条出边时，角色原路反弹，继续剩余步数。

#### 3.5.2 路面类型

每进入一个路面格，按该格的路面类型处理。路面类型同时决定“经过”和“停下”两种触发；在最后停下的格上，先处理 3.6.1 的脚下东西，再回到这里结算路面类型。

|---|---|---|

| 乐透 | 经过或停下 | 打开乐透面板；规则见下面“乐透” |
| 卡片 | 经过或停下 | 获得一张基础卡 |
| 金钱格 | 经过或停下 | 获得 1 到配置上限之间的现金 |
| 商店 | 停下 | 打开商店面板；规则见下面“商店” |
| 神秘人 | 停下 | 打开神秘人面板；规则见下面“神秘人” |
| 研究所 | 停下 | 打开研究所面板；规则见下面“研究所” |
| 魔法屋 | 停下 | 打开魔法屋选项；规则见下面“魔法屋” |

商店、神秘人、研究所、魔法屋、新闻、税、事件的面板关闭后，继续处理相邻地产。

**银行**：打开一次性存取款面板。面板只有一个现金/存款分配滑块，范围从 0 到“现金 + 存款”：最左是全部存入银行、现金为零，最右是全部放现金、存款为零，默认停在当前比例。确认一次即完成并关闭面板，不提供反复存取。存款按配置的周期和利率结息，利息进入存款。存款不直接参与购买，只在强制付款时作为第二资金来源。

**乐透**：一次访问只能买一注。号码范围、票价、开奖周期、初始奖池和奖池增长由配置给出。同一期全场同一个号码只能卖一次；已售号码不能再次购买。开奖时随机抽一个号码；无人中奖时奖池累计，票和已售号码保留；有人中奖后清空票和已售号码，奖池回到初始值。中奖金额进入现金。

**商店、神秘人、研究所**：展示数量和购买上限由配置给出。商店价格 = 卡片基础价 × 1；神秘人价格 = 卡片基础价 × 0.5；研究所价格 = 卡片基础价。商店展示基础卡；研究所展示进阶卡；神秘人按配置展示。买过的卡从列表消失；买满购买上限时自动关闭。

**魔法屋**：从以下效果中选择一项，一次停靠只能选一次，不花钱。需要目标的效果不会让玩家挑人：系统从“目标条件池”中随机抽一个条件，再在所有满足该条件的参赛者中随机抽一个作为目标。条件本身不可选择。

目标条件池：现金最多、现金最少、存款最多、存款最少、地产最多、地产最少、男性、女性、正在驾驶载具、没有驾驶载具、在监狱、不在监狱、在医院、不在医院、身上有神仙、身上没有神仙、站在有主地产旁、没有站在有主地产旁。

效果表：

1. **随机请神**：从地图上的神仙中随机取一位，附身到随机条件目标身上；地图没有神仙时改为随机一位神仙。
2. **获得三张卡片**：自己随机获得三张基础卡；手牌可以暂时超过上限，下一次自己回合开始时再弃牌。
3. **随机摧毁建筑**：随机条件目标的一处已建地产降一级；降到零后变成空地，归属不变。
4. **全部存入银行**：自己的全部现金立即转入存款。
5. **随机传送**：自己随机传送到一个空路面格，随机朝向，不触发落点。
6. **立即住院或入狱**：随机条件目标立即住院或入狱配置天数，位置移到对应入口。

**新闻与事件**：新闻和事件从同一张事件表抽取，按表结算一次。

| 事件 | 效果 |
|---|---|
| 物价上涨 | 物价指数增加配置步长 |
| 股市大涨 | 所有股票价格按配置比例上涨 |
| 股市大跌 | 所有股票价格按配置比例下跌 |
| 中奖 | 现金增加配置金额 × 物价指数 |
| 罚款 | 支付配置金额 × 物价指数 |
| 住院 | 住院配置天数 |
| 入狱 | 入狱配置天数 |
| 获得卡片 | 获得配置数量的随机基础卡 |
| 失去卡片 | 随机失去配置数量的手牌 |
| 全体发钱 | 每名参赛者现金增加配置金额 × 物价指数 |
| 全体收钱 | 每名参赛者支付配置金额 × 物价指数 |
| 传送 | 随机传送到一个空路面格，不触发落点 |

### 3.6 落点

移动结束后，停在最后一个路面格上，按以下顺序结算。

#### 3.6.1 脚下的东西

先处理落点格上的放置物：神仙、野狗、乞丐、地雷、炸药、定时炸弹、香蕉皮、果冻墙、陷阱、路障。每格最多一个放置物；角色不阻挡角色。

| 东西 | 效果 |
|---|---|
| 神仙 | 按 3.6.4 附身该神仙 |
| 野狗 | 住院配置天数；汽车和明确免疫野狗的技能可以躲开 |
| 乞丐 | 支付配置金额 × 物价指数；支付后乞丐消失 |
| 地雷 | 支付配置金额 × 物价指数，住院配置天数 |
| 炸药 | 支付配置金额 × 物价指数，住院配置天数 |
| 定时炸弹 | 附身到经过者，按配置步数倒计时，爆炸后支付配置金额 × 物价指数 |
| 香蕉皮 | 停下触发，强制向前移动 1 格；路口随机选方向；新格若还是香蕉皮继续连锁，之后从移动阶段继续正常结算 |
| 果冻墙 | 弹回配置步数，不损失钱 |
| 陷阱 | 停留配置天数 |
| 路障 | 经过时停止移动，剩余步数取消 |

所有道具共用一套流程，不做特例。经过触发和停下触发分开：经过触发分为保留步数和不保留步数；传送门经过时随机传送但保留剩余步数，继续移动；果冻墙经过时弹回、不保留剩余步数。停下触发的强制位移把流程送回移动阶段，从移动阶段重新往后处理；如果移动后新格又触发强制移动，就继续连锁。强制移动后的新格仍按正常顺序处理路面类型、相邻地产、神仙和方向。强制移动地块也用同一套流程，只是在可放置物之后处理。

#### 3.6.2 路面类型

脚下东西处理完后，按 3.5.2 的路面表结算当前格的路面类型。已经经过但不停下的格只按经过触发结算，不执行停下效果。

#### 3.6.3 相邻地产

所有和当前路面正交共边的地产按地块 id 顺序逐块结算。每块按以下顺序：

1. 对手地产：支付租金。
2. 己方地产（自己或队友）：不付租金；空地则建造，已建则升级。建造费和升级费由当前停留者支付，地产归属不变，建筑为整个队伍服务。
3. 无主地产：询问买不买；买下或放弃后继续下一块。

一个路面同时贴多块地产时，必须逐块处理，处理完才进入下一步。队友地产和自己地产在建造、升级、收租归属和队伍效果上没有区别；唯一区别是归属权在队友身上，队友破产后该地产变为无主。

**买地**：无主地产被询问时，支付配置的购买价，地产归购买者，状态变为空地。购买价乘以当前物价指数。购买只能用现金。

**建造**：停到己方空地相邻路面时建造：

- 小地产：建造唯一的小房屋，等级变为 1。
- 大地产：从大建筑表中选择一种建筑，等级变为 1。公园不能在这里选，只能由改建卡产生。

建造费乘以当前物价指数。建造只能用现金。

**升级**：停到己方已建地产相邻路面时升级：

- 小房屋：等级加一，最高等级由配置给出。
- 大建筑：等级加一，最高等级由配置给出。

升级费乘以当前物价指数。升级只能用现金。

空地和升级没有关系：空地只能先建造，已建地产才能升级。大空地不是“大建筑等级 0”，它没有建筑类型。

**租金**：小地产租金 = 基础租金 × 物价指数 × 街区倍率。基础租金由地产等级和配置给出；街区倍率按同一队伍、同一街区内已建成的小房屋数量计算，空地面和大地产不计入数量。归属只决定租金进入谁的存款，不改变队伍倍率。停业状态租金为零；涨价状态租金翻倍。大地产租金按大建筑类型和等级单独计算，见下面“大建筑”。

地产不能主动出售。破产时地产归属清空，建筑和等级保留；其他参赛者再买下时保留原层数和建筑类型。

**大建筑**：大地产建造后，按建筑类型产生效果。最高等级由配置给出，建造费和升级费按配置乘以物价指数。

| 建筑 | 效果 |
|---|---|
| 商业中心 | 对手停在此格时支付租金：基础租金 × 等级 × 物价指数 × 转盘数 |
| 大饭店 | 对手停在此格时支付基础租金 × 等级 × 物价指数，并被强制住店配置天数 |
| 地产公司 | 己方应付租金降低配置比例 × 等级，最高不超过配置上限 |
| 书店 | 己方离开商店或神秘人时，按等级对应的概率获得若干张卡 |
| 能源中心 | 对手买卡价格增加配置比例 × 等级；己方任意角色停在此格获得配置金额 × 等级 × 物价指数 |
| 研究所 | 研发进阶卡；等级决定可研发卡池，最多展示配置数量 |
| 公园 | 不收费、不加成；只能由改建卡把其他大建筑改成公园 |

改建卡可以更换大建筑的设施类型；工程车卡和怪兽卡每次降一级；等级降到零后大建筑消失，恢复大空地。

#### 3.6.4 神仙与事后神

落点、路面类型和相邻地产结算完后，如果当前神仙有“落点后”效果，结算该效果。神仙同时占用绑定槽，基础附身天数由配置给出；新神仙顶替旧神仙，旧神仙没有补偿。

| 穷神 | 向每位对手赠送配置金额 | 租金和付费翻倍 | 无 |
| 福神 | 获得配置数量的随机基础卡 | 停在己方地产免费加盖一层 | 己方相邻地产各免费加盖一层 |
| 衰神 | 随机失去配置数量的手牌 | 走到己方地产不能加盖 | 无 |
| 天使 | 无 | 走到任何地产，该地免费加盖一层 | 所有相邻地产各免费加盖一层 |
| 恶魔 | 无 | 走到任何地产，该地下降一层；空地不破坏 | 无 |
| 土地公 | 无 | 走到非己方地产，将其占为己有 | 收走所有非己方相邻地产 |

#### 3.6.5 方向

停在交叉点时，合法方向是除当前朝向外所有可走方向；如果当前朝向不是合法出边，则所有出边都可选。选中方向后，角色朝该方向，下一回合从该方向出发。移动中的朝向始终等于实际前进方向，不会出现向下走却朝右。

每次移动结束且没有待选方向时，角色朝向固定为前方非来路方向。

### 3.7 回合结束

所有落点结算完成后，进入回合结束：处理“回合结束”技能；当前角色的绑定槽、人物槽和物理槽剩余计数各减一，减到零的状态结束。

然后换下一名参赛者。最后一名参赛者的回合结束后，天数加一；天数超过配置上限时，游戏结束，按第 6 节结算胜负。

## 4. 资金与破产

现金和存款是两种资金。所有金额先乘物价指数（配置明确写“不乘”的除外）。

**强制付款**（租金、税、罚款、事件损失、爆炸损失）按以下顺序扣：

1. 先扣现金。
2. 现金不足时，扣存款。
3. 现金和存款都扣完仍不足以支付时，现金和存款都归零，宣布破产。

**主动购买**（买地、建造、升级、买卡、买股票、买乐透）只能用现金；现金不足时不能购买，不能自动从存款扣。

租金进入收款人的存款，不进入现金。工资、事件奖励和卡片奖励进入现金。

资产 = 现金 + 存款 + 地产估值 + 股票市值。地产估值 = 购买价 + 已付建造费。

破产时，破产者退出游戏，地产归属清空但建筑保留，手牌移出游戏。破产者的债权人先拿走剩余现金和存款，再处理地产归属。

## 5. 操作

开局界面生成本地配置：参赛者、控制者、队伍、角色、地图、所有可调参数、种子。开始后进入棋盘。

右侧栏从上到下是：

- 天数、物价和股票按钮。
- 每名参赛者一行：头像、角色、队伍、现金、存款、位置、朝向、三个状态槽。
- 日志。
- 底部情境区：平时显示骰子和手牌；需要选择时切换成买地、建造、升级、方向、商店、乐透、银行、股票、魔法屋、神秘人或卡片目标面板。

操作规则：

- 点骰子掷骰；掷骰后不能再用卡或买卖。
- 点手牌使用卡片；响应卡不能主动点。
- 点地图上的地产、路面或角色选择空间目标。
- 点右侧栏按钮确认或取消面板操作。
- 金额、卡片、状态变化以浮动文字显示在角色头顶。

## 6. 胜负

满足任一条件时游戏结束：

- 只剩一支队伍。
- 天数达到配置上限。

游戏结束时，队伍总资产 = 队伍所有成员现金 + 存款 + 地产估值 + 股票市值。总资产最高的队伍获胜；并列时依次比较存款、地产数量、随机种子决定的顺序。

破产者退出游戏。破产者的队伍如果全部破产，该队伍失败；否则继续比较剩余队伍。

## 7. AI 操作

AI 和人类使用同一套规则与同一个行动入口，不读取隐藏信息。每回合按配置的评分表决策：保命响应优先，其次购买、建造、升级、用卡、移动目标。AI 不使用 LLM，不访问网络，不读取随机种子之外的未来信息。
