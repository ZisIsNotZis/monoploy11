# 必须为真

数值与规则的唯一事实来源是 `docs/data/`；本文件只规定“必须存在什么”，具体数值不在此重复。

## 功能

### 对局

- 任意 N 名参赛者（默认 4），可全部为 AI、人类与 AI 混合；原版联机上限 4 人，N > 4 为本复刻的扩展，引擎不得写死 4。
- 支持组队/结盟：同队互免租金、可帮队友加盖、共享胜利判定；结盟关系可配置（固定队伍或对局中缔结）。
- 挑战模式：N 名挑战者 + 1 名领主；领主拥有初始资金、初始地产与三档天赋；以领主破产为结算点，队伍总资产最高者胜。
- 自由模式：所有对手破产，或到达设定时间时资产最高者胜。
- 热斗模式：只有大型地产，爆炸直接扣钱、不进医院，伤害卡格产出。
- 抢房模式：部分地块开局自带建筑，围绕其争夺。

### 回合与移动

- 掷骰、双骰/载具、遥控骰子、转向、乌龟、梦游、冬眠、停留、路障、传送、陷阱。
- 医院/监狱的进入、停留、保释、出狱。
- 物价指数随天数上涨，并影响租金、热斗金钱增减、乐透与新闻收支。
- 回合内可执行：使用卡片、买卖股票、存取款、购买/升级地产、使用机关、结束回合。

### 地产与经济

- 空地购买、建房、加盖、等级上限、同街道连锁租金加成、大地产与小地产区别。
- 七种大建筑：商业中心、大饭店、地产公司、书店、能源中心、研究所、公园；各有等级与功能。
- 改建、停业、涨价、降价、摧毁、占领、交换。
- 现金与存款分离；银行存款/取款/利息。
- 股票买卖、股价波动、新闻影响。
- 乐透购买、开奖周期、奖级。
- 商店购买卡片（货架、刷新、限购、价格）；研究所研发卡片。
- 神秘商人低价卡、野狗、乞丐、新闻事件、魔法屋。

### 卡片

- 全部基础卡、被动卡、进阶卡；五张同名卡自动合成进阶卡。
- 使用距离、目标合法性、对领主免疫规则、无懈/转移的响应链。
- 手牌上限（普通角色与领主不同）与超限替换规则。

### 神仙

- 十位神仙的传统/热斗效果、附身天数、请神/送神/换神、角色天赋对天数的修正。

### 角色与领主

- 16 名角色的两个天赋，全部按原版触发条件生效。
- 4 位领主 × 3 档难度，逐档解锁技能；领主免疫指定卡片。
- 角色天赋可整体关闭（原版自定义选项）。

### 地图

- 16 张地图的拓扑等价复刻：节点、边、单向/转向、上下层、传送、车站、机关改变连接。
- 每张图的机关、特殊格分布、起始点。
- 地图以数据描述，渲染层与规则层分离；新增地图不改引擎。

### 表现

- 纯前端单页，无后端、无登录、无外部素材请求。
- 棋盘用文字/色块/SVG 绘制；角色、卡片、神仙、建筑用文字与颜色区分。
- 无音乐、无语音、无动画依赖；操作有即时文字反馈与日志。
- 桌面与移动浏览器可用；断网可玩。

## 非功能

- 确定性：固定随机种子可重放整局；规则层不直接调用 `Math.random`。
- 可测：核心规则为纯函数/状态机，可在 Node 中无头跑完整对局与单元测试。
- 性能：一局 10 万次模拟在普通笔记本上可接受；浏览器单局操作无卡顿。
- 可维护：卡片、角色、神仙、建筑、地图均为数据表 + 效果解释器，新增内容不改核心。
- 可发布：静态文件可部署到任意静态托管，构建产物不含 node_modules。

## 约束

- 非商业同人复刻；不使用原版美术、音频、字体、UI 素材；不打包原版资源。
- 角色名、卡片名、地名作为规则事实引用；如发布公开仓库，README 注明非官方。
- 预算 ¥0：无付费 API、无付费素材、无服务器。
- 不引入运行时框架依赖；构建工具可用，产物必须是纯静态。

## 验收的总口径

“规则完整”以 `docs/data/` 覆盖的条目为准：每一条数据都必须有一个可执行的效果或一个明确的“未证实/不复刻”标记；未标记的缺失视为缺陷。
