# Monopoly 11 规则书

## 1. 这是什么游戏

Monopoly 11 是一款回合制棋盘游戏。2 名或更多参赛者轮流掷骰、沿道路移动、购买地产、建造房屋、收取租金、使用卡片、经营现金和存款，最后按队伍总资产或破产结果决出胜负。

一局至少 2 名参赛者，没有人数上限；界面默认 4 名。每名参赛者独立选择人类或 AI、队伍、颜色；全人类、全 AI、人机混合都合法。所有参赛者在同一台设备上轮流操作，所有操作在本地完成。

一局中至多一名参赛者可以是 BOSS 角色。BOSS 不是另一种游戏规则；它只是一名初始配置和技能不同的特殊参赛者，和所有人一起排队、掷骰、买地、收租、破产。BOSS 有三个档位：简单、普通、困难，每个档位启用不同技能。人类可以操控 BOSS，AI 也可以操控 BOSS。

队伍可以任意分组：每人一队、两人一队、所有人一队、BOSS 单独一队都合法。队伍总资产最高的队伍获胜。

## 2. 棋盘

棋盘是一张 25×17 的二维网格，每格 44×44 像素。棋盘由三层组成：

- **路面层**：1×1 的可走格。每格有一个类型：空路、银行、商店、新闻、卡片、乐透、魔法屋、税、事件、医院、监狱、传送门、起点。
- **地产层**：路边不可走的格。小地产占 1×1，大地产占一整块 2×2。地产通过正交共边和路面相邻；对角接触不算相邻。
- **放置物层**：路面上的东西，每格最多一个。角色不占格，一格可以站多名角色。

每块地产至少有一条边贴路。街区按物理连接计算：连在一起的小地产和大地产属于同一街区，不管归谁。每个街区最多 5 块地产，街区之间留空；每个街区最多 1 块大地产。

大地产是一块地产，不是四块小地产，也不是两格路。大地产提供街区连通性，但不计入小房屋的街区租金加成。

死路走到尽头后原路反弹，继续剩余步数。传送门是可选路面类型，不是死路的出口。

## 3. 开局

开局时确定：

- 参赛者数量、名字、人类或 AI、队伍、颜色。
- 是否有一名 BOSS、BOSS 是谁、BOSS 档位。
- 随机种子；相同种子和相同配置产生同一局。

每名参赛者初始现金 100,000，初始存款 100,000，初始手牌 3 张随机基础卡。

所有参赛者随机落在不同的路面格，随机朝向一个合法方向。起始格不触发任何结算。

所有地产开局为空地：小地产是空地面，大地产是大空地。BOSS 也没有初始地产。

## 4. 回合

一局按回合循环。每名参赛者的回合按以下顺序执行：

1. **弃牌**：手牌超过上限时，弃到上限。上限是 8 张；只有明确写“手牌上限改为 X”的技能能改变它。
2. **行动**：可以使用手牌、进入银行面板、买卖股票。银行只有在经过或停在银行格时才能打开。
3. **掷骰**：按载具掷骰，步行 1 颗、机车 2 颗、汽车 3 颗，取点数之和。
4. **移动**：沿路面逐格前进，每格结算经过事件。
5. **落点结算**：按第 6 节的固定顺序处理。
6. **事后神**：处理福神、天使、土地公、凶神。
7. **方向**：如果停在交叉点，选择新方向。
8. **结束回合**：处理回合结束状态，换下一名参赛者。

掷骰之后不能再使用卡片、买卖股票或存取款。只有移动、落点、相邻地产、事后神和方向全部结束后，才换下一名参赛者。

回合开始时，绑定槽和人物槽的剩余天数减 1；物理槽的住院/入狱回合数减 1。梦游、冬眠状态跳过本回合的行动和移动；乌龟状态本回合只能走 1 步；冰冻状态本回合点数视为 0，并在原地再触发一次落点。

## 5. 移动与方向

移动沿路面正交邻接逐格进行。每走到一格，先结算该格的经过事件，再继续走下一格。

经过交叉点但不停下时，随机选择一个非来路方向，继续剩余步数。正好停在交叉点时，不立即选方向；等落点、相邻地产、事后神全部结算完，再选择方向。

停在交叉点时，合法方向是除当前朝向外所有可走方向；如果当前朝向不是合法出边，则所有出边都可选。选中方向后，角色朝该方向，回合结束。

死路只有一条出边时，角色原路反弹，继续剩余步数。

每次移动结束且没有待选方向时，角色朝向固定为前方非来路方向。这样下一次掷骰前，玩家能看到角色朝哪边走。

## 6. 落点结算顺序

停在一个路面格后，严格按以下顺序结算：

1. **脚下的东西**：神仙、野狗、乞丐、神秘人、地雷、炸药、定时炸弹、香蕉皮、果冻墙、陷阱、路障。
2. **路面类型**：卡片、银行、乐透、商店、魔法屋、新闻、税、事件、传送、医院、监狱、起点。
3. **相邻地产**：所有和该路面正交共边的地产，按地块 id 顺序逐块结算。
4. **事后神**：福神、天使、土地公、凶神。
5. **方向**：如果停在交叉点，选择方向。

相邻地产的结算顺序：

1. 对手地产：支付租金，租金进入房东存款。
2. 队友地产：不付租金。
3. 自己的小地产：已有房屋则加盖一层；空地面则建第一层。
4. 自己的大空地：选择一种大建筑。
5. 无主地产：逐块询问买不买；买下或放弃后继续问下一块。

一个路面同时贴多块无主地产时，必须逐块询问，问完才进入下一步。

## 7. 经过与停下

经过和停下是两种不同触发：

- **经过触发**：银行、乐透、卡片格、地面道具。经过时立即结算；银行面板关闭后继续剩余移动。
- **停下触发**：商店、神秘人、研究所、魔法屋、新闻、税、事件、医院、监狱、传送门。只在正好停在上面时触发；经过不触发。

新闻停在上面时立即结算一条新闻，不要求再点“看新闻”；结算完继续相邻地产。

## 8. 路面类型

| 类型 | 触发 | 效果 |
|---|---|---|
| 空路 | 无 | 无 |
| 银行 | 经过或停下 | 打开存取款面板；存款、取款可反复操作，关闭后继续移动 |
| 乐透 | 经过或停下 | 打开乐透面板；一次访问只能买一注 |
| 卡片 | 经过或停下 | 随机获得 1 张基础卡 |
| 商店 | 停下 | 从基础卡中随机展示 9 张不重复的卡，每张 2,000，最多买 3 张；买过的卡立即消失，买满自动关闭 |
| 神秘人 | 停下 | 从基础卡中随机展示 6 张不重复的卡，每张 1,000，最多买 2 张；买过的卡消失，买满自动关闭 |
| 研究所 | 停下 | 展示 6 张进阶卡，每张 10,000，最多研发 2 张 |
| 魔法屋 | 停下 | 六选一，见第 14 节 |
| 新闻 | 停下 | 立即结算一条新闻，见第 15 节 |
| 税 | 停下 | 支付现金的 5%，最低 5,000，最高 50,000 |
| 事件 | 停下 | 从事件表抽一条，见第 15 节 |
| 医院 | 进入 | 住院 2 回合，位置移到医院入口；出院回到入口 |
| 监狱 | 进入 | 入狱 2 回合，位置移到监狱入口；出狱回到入口 |
| 传送门 | 停下 | 移动到配对的传送门，不触发落点 |
| 起点 | 经过 | 获得 20,000 工资；起始格不触发 |

商店、神秘人、研究所、魔法屋、新闻、税、事件的面板关闭后，继续处理相邻地产。

## 9. 地产与租金

### 小地产

- 购买价：8,000。
- 买下后是空地面，等级 0，不产生租金。
- 下一次停到相邻路面时建第一层，等级 1。
- 之后每次停到相邻路面，升 1 级，最高 5 级。
- 建造/升级费用：目标等级 × 5,000。升到 1 级 5,000，2 级 10,000，3 级 15,000，4 级 20,000，5 级 25,000。
- 基础租金：等级 1 为 2,000，之后每级翻倍：2,000 / 4,000 / 8,000 / 16,000 / 32,000。

### 大地产

- 购买价：20,000。
- 买下后是大空地，没有建筑。
- 下一次停到相邻路面时，从商业中心、大饭店、地产公司、书店、能源中心、研究所中选一种建造；公园只能由改建卡产生。
- 建造费 30,000；之后每升 1 级支付 30,000，最高 5 级。

### 街区租金

一条街区内，同一所有者已经建成的小房屋数量记为 N，N 最大 5。街区倍率 = 1 + 0.4 × (N - 1)，所以 1 栋 1.0 倍、2 栋 1.4 倍、3 栋 1.8 倍、4 栋 2.2 倍、5 栋 2.6 倍。

小地产租金 = 基础租金 × 物价指数 × 街区倍率。空地面和大地产不计入 N。停业状态租金为 0；涨价状态租金翻倍。

大地产租金按建筑类型单独计算，见第 13 节。地产不能主动出售；只有破产会清空归属。

### 破产

现金不足以支付时破产。破产者退出游戏，地产归属清空，但建筑和等级保留；其他参赛者再买下时保留原层数和建筑类型。破产者的手牌移出游戏。

## 10. 现金、存款、股票、乐透

物价指数从 1 开始，每 15 天增加 0.1，影响租金、税费、事件和野狗等固定金额。现金和存款分开。买地、建房、买卡、买股票、买乐透、纳税、罚款只用现金。租金进入房东存款。资产 = 现金 + 存款 + 地产估值；地产估值 = 购买价 + 已付建造费。

存款每 30 天结息一次，利率 10%，利息进入存款。

股票随时可以买卖，不需要股票格。股票共 8 支：银行股、地产股、科技股、能源股、媒体股、医药股、消费股、交通股。每支初始价格 50，持股数量为非负整数，不能做空。买入用现金，卖出回现金。每天每支股票随机变动 −10% 到 +10%，四舍五入到整数；单日涨跌幅上限 ±10%。

乐透号码 1–30。同一期全场同一个号码只能卖一次。一次访问只能买一注，票价 2,000。每 10 天开奖一次，随机抽一个号码；无人中奖时奖池累计，票和已售号码保留，已售号码继续不能买；有人中奖后清空票和号码，奖池回到 200,000。

## 11. 卡片

卡组 48 张，分基础卡和进阶卡。基础卡从商店、神秘人、卡片格、事件获得；进阶卡由五张同名基础卡自动合成。

手牌上限 8 张；超过上限只在本人回合开始时弃牌。手牌没有其他上限。

五合一配方：

- 5 张飞弹卡 → 急速弹卡
- 5 张涨价卡 → 辉煌卡
- 5 张停业卡 → 窘困卡
- 5 张送神卡 → 绿化卡
- 5 张怪兽卡 → 灾祸卡
- 5 张请神卡 → 神眷卡

### 卡片目标

- 自身卡：直接使用。
- 角色卡：点角色；范围 5 步。转向、停留、乌龟可以选自己，其他角色卡不能选自己。
- 地块卡：点地产；范围 5 步。机器工人和工程车点己方地产；购地卡、换屋卡、改建卡、怪兽卡按卡面指定。
- 街区卡：点街区内任意地产，按该地产所在街区结算。
- 路面卡：点路面；范围 5 步。
- 全场卡：不需要目标。
- 机器娃娃：点 10 步内一点，沿路径清除障碍。
- 遥控骰子：在本次移动范围内点目的地。

### 响应卡

响应卡在对应时机自动询问，手牌里显示为灰色，不能主动点击。

- **免费卡**：单次付款达到 10,000 时询问；消耗后取消本次付款。
- **无懈卡**：对手对你使用指向性卡片时询问；消耗后取消该卡。
- **转移卡**：你入狱、入院或单次损失达到 10,000 时询问；消耗后选择另一名合法角色承担。
- **同命卡**：对手对你使用梦游、冬眠或谋划时询问；消耗后把同一效果反弹给使用者。

## 12. 神仙

神仙占用绑定槽，基础附身 3 天。新神仙顶替旧神仙，旧神仙直接离开，没有补偿。神仙效果分“附身时”一次性结算和“附身期间”持续效果。

| 神仙 | 附身时 | 附身期间 |
|---|---|---|
| 财神 | 向每位对手收取 20,000 | 免除租金和付费 |
| 穷神 | 向每位对手赠送 20,000 | 租金和付费翻倍 |
| 福神 | 获得 2 张随机基础卡 | 停在己方地产免费加盖 1 层 |
| 衰神 | 随机失去 2 张手牌 | 走到己方地产不能加盖 |
| 天使 | 无 | 走到任何地产，该地免费加盖 1 层 |
| 恶魔 | 无 | 走到任何地产，该地下降 1 层；空地不破坏 |
| 土地公 | 无 | 走到非己方地产，将其占为己有 |
| 糊涂神 | 无 | 每次前进随机转向；使用卡片有 30% 失败，失败不退还卡片 |
| 武神 | 无 | 所有卡片使用范围 +3 步 |
| 凶神 | 无 | 税、事件、新闻、野狗、乞丐对自身无效 |

## 13. 大建筑

大建筑最高 5 级。建造费 30,000，升级费 30,000/级。

| 建筑 | 效果 |
|---|---|
| 商业中心 | 对手停在此格时支付租金：3,000 × 等级 × 物价指数 × 转盘数（转盘 1–6） |
| 大饭店 | 对手停在此格时支付 1,000 × 等级 × 物价指数，并被强制住店 2 回合 |
| 地产公司 | 己方应付租金降低 10% × 等级，最高 50% |
| 书店 | 己方离开商店或神秘人时，有 20% + 10% × 等级的概率获得 1–3 张卡 |
| 能源中心 | 对手买卡价格增加 10% × 等级；自己停在此格获得 10,000 × 等级 × 物价指数 |
| 研究所 | 研发进阶卡；等级决定可研发卡池，最多同时展示 6 张 |
| 公园 | 不收费、不加成；只能由改建卡把其他大建筑改成公园 |

## 14. 魔法屋

停在魔法屋后，从六项中选一项。一次停靠只能选一次，不花钱。没有合法目标的选项变灰；选择目标时取消会回到六项菜单，不消耗这次停靠。

1. **获得三张卡片**：随机获得 3 张基础卡。手牌可以暂时超过 8 张，下一次自己回合开始时再弃牌。
2. **天降横财**：现金 +30,000。
3. **免费加盖**：选择己方一处已建成、未停业的小地产，等级 +1，最高 5 级。
4. **强制降级**：选择对手一处已建成的小地产，等级 −1，最低为 0；不删除地产、不改归属。
5. **神仙附身**：随机一位神仙附身 3 天，顶替当前神仙；不立刻触发该神仙的落点效果。
6. **牢狱之灾**：选择一名不在监狱、不在医院的对手，入狱 2 回合并移到监狱入口。

## 15. 新闻与事件

新闻和事件从同一张事件表抽取，按表结算一次。新闻停在新闻格触发；事件停在事件格触发。

| 事件 | 效果 |
|---|---|
| 物价上涨 | 物价指数 +0.1 |
| 股市大涨 | 所有股票价格 +10% |
| 股市大跌 | 所有股票价格 −10% |
| 中奖 | 现金 +20,000 |
| 罚款 | 现金 −10,000 |
| 住院 | 住院 2 回合 |
| 入狱 | 入狱 2 回合 |
| 获得卡片 | 获得 2 张随机基础卡 |
| 失去卡片 | 随机失去 1 张手牌 |
| 全体发钱 | 每名参赛者现金 +10,000 |
| 全体收钱 | 每名参赛者现金 −10,000 |
| 传送 | 随机传送到一个空路面格，不触发落点 |

事件金额受物价指数影响：表中固定金额乘以当前物价指数。

## 16. 野狗、乞丐与地面道具

爆炸伤害指地雷、炸药、飞弹、定时炸弹造成的金钱损失；住院部分不受爆炸增减影响。

| 东西 | 触发 | 效果 |
|---|---|---|
| 野狗 | 经过或停下 | 50% 住院 2 回合，50% 损失 5,000；汽车和明确免疫野狗的技能可以躲开 |
| 乞丐 | 经过或停下 | 支付 5,000 × 物价指数；支付后乞丐消失 |
| 地雷 | 经过 | 损失 20,000 × 物价指数，住院 2 回合 |
| 炸药 | 经过 | 损失 20,000 × 物价指数，住院 2 回合 |
| 定时炸弹 | 经过 | 附身到经过者，30 步后爆炸，损失 30,000 × 物价指数 |
| 香蕉皮 | 经过 | 损失 5,000 × 物价指数 |
| 果冻墙 | 经过 | 弹回 2 格，不损失钱 |
| 陷阱 | 经过 | 停留 1 回合 |
| 路障 | 经过 | 停止移动，剩余步数取消 |

放置物每格最多一个。开局不生成；第 3 天起每天在空路面随机刷新 1 个，已有角色或已有放置物的格子跳过。

## 17. 状态

每名参赛者有三个状态槽：

- **绑定槽**：神仙、定时炸弹，按天或步数倒计时。
- **人物槽**：乌龟、梦游、冬眠、冰冻、停留，按天倒计时。
- **物理槽**：监狱、医院，按回合倒计时。

同槽新状态顶替旧状态。梦游和冬眠跳过回合；乌龟每次只能走 1 步；冰冻点数视为 0 并原地再触发一次落点；停留跳过本回合移动。

## 20. 胜负

满足任一条件时游戏结束：

- 只剩一支队伍。
- 天数达到上限 100 天。

游戏结束时，队伍总资产 = 队伍所有成员现金 + 存款 + 地产估值。总资产最高的队伍获胜；并列时比较存款，存款高者获胜；仍并列则比较地产数量。

破产者退出游戏。BOSS 破产时 BOSS 所属队伍失败；如果场上还有多支其他队伍，继续比较剩余队伍总资产。

## 21. 操作

开局界面选择人数、队伍、每名参赛者人类或 AI、是否加入 BOSS、BOSS 和档位、种子。开始后进入棋盘。

右侧栏从上到下是：

- 天数和物价。
- 每名参赛者一行：头像、名字、队伍、现金、存款、位置、朝向、三个状态槽。
- 日志：显示最近发生的事，自动滚到底。
- 底部情境区：平时显示骰子和手牌；需要选择时切换成买地、加盖、大建筑、方向、商店、乐透、银行、股票、魔法屋、神秘人或卡片目标面板。

操作规则：

- 点骰子掷骰；掷骰后不能再用卡或买卖。
- 点手牌使用卡片；灰色响应卡不能主动点。
- 点地图上的地产、路面或角色选择空间目标。
- 点右侧栏按钮确认或取消面板操作。
- 金额、卡片、状态变化以浮动文字显示在角色头顶。
- 没有重开按钮、没有银行按钮；股票按钮常驻。

## 22. AI 操作

AI 和人类使用同一套规则与同一个行动入口，不读取隐藏信息。每回合按以下顺序决策：

1. 手牌超过上限时，弃掉最不常用的卡，直到上限。
2. 能付款保命时，优先使用免费卡、无懈卡、转移卡、同命卡。
3. 有可购买地产且现金 − 价格 ≥ 30,000 时买地；否则放弃。
4. 有己方地产可加盖且现金 − 费用 ≥ 30,000 时加盖；否则保留现金。
5. 有攻击卡时，优先选择总资产最高的对手；有增益卡时优先给自己或队友。
6. 掷骰后按规则移动，不反悔。

AI 不使用 LLM，不访问网络，不读取随机种子之外的未来信息。
